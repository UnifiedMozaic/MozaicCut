# MozaicCut の画面のデザイン

この文書は、MozaicCut の編集画面（UM で書き、SDL3 のウィンドウに描く UI）のデザインを決めるものです。
画面を作る人・AI は、ここに書いた配置・部品・キー・文言・色を守ってください。形を変えたいときは、先にこの文書と [tokens.json](tokens.json) を直します。

- 色・文字・寸法・動きの値の正本は [tokens.json](tokens.json) です。この文書に書いた値と食い違ったら、tokens.json が正しいものとします。
- 見た目の見本は [mockups/](mockups/) の HTML です（1440×900 の論理 px で作っています。ブラウザで開けば見られます。edit.html は `?w=1024` と `?w=1920` で窓の幅を替えられます）。
- 内部の約束ごと（モジュール・型・操作）は [architecture.md](architecture.md)、AI のエージェント向けの手引きは [../ai.md](../ai.md) にあります。

## 0. 決め方（3 つの案から何を採ったか）

デザインは、3 つの案を 4 つの立場（プロの編集者、初めての人、AI との協業、実装する人）で採点して決めました。

| 案 | 中身 | 採点の合計（40 点満点） |
|---|---|---|
| 集中できる編集（focus） | 迷わない固定の配置、道具は文脈で出す、ツールは 3 つ | **29**（土台にした） |
| 共有台帳（collab） | 人・AI・テキストが同じ台帳を編む。AI は提案だけ | 27 |
| プロの道具（pro） | 中立のグレーで密度が高い、キーボード中心、トリムモードの作り込み | 26 |

**土台は focus**（初めての人と実装の両方で最高点）。そこに次のものを足し、次のものを避けました。

| 採ったもの | どの案から | 理由 |
|---|---|---|
| 固定の分割の配置（領域の幅と高さだけを持つ）、集中モード、ツール 3 つ、文脈の操作の欄、上の帯の［書き出す…］、アイコンを glyf のフォントにする、性能の予算 | focus | 初めての人が迷わず、作る量が少なく、テストしやすい |
| トリムの作り込み（A/B の並べ表示、−10/−1/+1/+10、確定前に「変わる値・影響・適用する op と .mzc の差分」を見せる） | pro | プロが一番欲しい「押す前に結果が分かる」。op を見せるので「操作の仕組みは一つ」も伝わる |
| クリップの面を暗くし、上の辺に 2px の種類の印。メーターを編集の作業画面に常に出す。アクティブなパネルを上の辺 2px で示す | pro | 白い文字の読みやすさ（8:1 前後）、音の事故の防止、Delete の受け手の明示 |
| AI の変更は「提案」として届き、人が確認して適用するまで書かない。一部の適用は「選んだ op だけの新しいバッチを dry-run し直す」。人が確認している最中の再計算。AI に見せる文脈の札。書き手（人・AI・テキスト）つきの履歴を `.mzc.history` に残す。インスペクタの値と .mzc のトークンの対応。参照の点線の矢印。書き出しの前の check | collab | AI との協業の核。既存のバッチ・dry-run・取り消しにそのまま乗る |
| 字幕の道筋（字幕のトラック、その場で打つ、SRT の読み書き）、空のタイムラインの「最初の 4 歩」、レールの文字のラベル | 採点で新たに出た考え | 初めての人が AI なしで 10 分で「切って・字幕を付けて・書き出す」まで届くように |

| 避けたもの | どこにあったか | 代わりにどうするか |
|---|---|---|
| Delete を「詰める」にする | collab | **Delete は隙間を残す（リフト）、Shift+Delete は詰める（リップル削除）。どの配列でも同じ意味** |
| 時刻を秒の小数のまま持ち、画面のコマ数とファイルの値がずれる | pro の `+0.2` 秒を「+6 コマ」と出す例 | 編集の時刻はすべてコマの境目に量子化する（4.7） |
| 操作に応じて配置が勝手に変わる（トリムで左の欄を畳む・拡大率を変える・右の列を組み替える・アイコンが出たり消えたりする） | focus、collab | 配置は人が変えたときだけ変わる。トリムや提案の確認は、決まった枠の「中身」だけを替える |
| クリップの見出しの主を ID にする | collab | 見出しは名前。ID はインスペクタの札・ツールチップ・「ID をコピー」・表示の切り替え（「ID を見出しに出す」）で必ず引ける |
| M1 で自由なドッキング | pro | M1 は固定の分割。自由なドッキングは M3 以降 |
| スナップの一時解除を Shift にする | collab | ドラッグ中にスナップのキー（標準 N ／ Premiere 互換 S）を押すと、そのドラッグの間だけ切り替える（Premiere と同じ）。Shift は複数選択、Alt はドラッグの前に押すと複製（4.8 の修飾キーの表） |
| SVG のパーサーを先に作る | pro | アイコンは私用領域の glyf のフォントにして ttf.um で描く |
| 標準の配列の中で流儀を混ぜる | pro の選択ツール A | 標準は Premiere の筋肉の記憶に寄せ、分割・スナップだけ多数派（Resolve・FCP・CapCut）に合わせる |

## 1. 原則

判断に迷ったら、上から順に優先します。

1. **作品が主役。** UI は R=G=B の無彩色の暗いグレーにする。彩度の高い色は、選択の枠・再生ヘッド・トリムのローラー・種類の印など小さな面積にだけ使う。映像のまわりは UI よりさらに暗い `bg.viewer`。
2. **手が迷わない。** Space・J/K/L・I/O・X・←→・↑↓・Home/End・M・F・Ctrl+Z は業界の共通の割り当てのまま。Premiere 互換・Resolve 互換の配列を最初から用意する。キーは物理キーで判定し、日本語の IME がオンでも効く。
3. **迷わない既定の配置。** 配置は固定の分割に「表示と非表示」と「境目のドラッグ」だけを足したもの。いつでも「既定の配置に戻す」。配置は人が変えたときだけ変わる。
4. **道具は文脈で出す。ただし位置は動かさない。** インスペクタは選んだものに合わせて中身を変え、タイムラインの帯の中央は「選んだものに効く操作」の欄になる。枠の位置と大きさは変えない。
5. **詰めるか、詰めないかを必ず見せる。** 詰める（リップル・挿入・詰めて削除・Q/W）は黄 `ripple`、詰めない（上書き・削除で隙間を残す・ロール・スリップ・スライド）は桃 `overwrite`。色に加えて、ボタンの文言（「詰めて削除」「削除（隙間を残す）」）とモードの札で示す。
6. **操作の仕組みは一つ。** キー・メニュー・右クリック・ボタン・コマンドパレット・AI は、どれも同じコマンドの ID を呼び、同じ op（`move` `trim` `split` `delete` `cut` `set` `unset` `renamekey` `add` `rename`）を作る。画面は「呼び出し方」を増やすだけで、操作そのものは増やさない。どのコマンドがどの op になるかは 5.2 の表で決める。**.mzc にまだキーや op がない操作（速度・パン・有効と無効・マーカー・キーフレーム・トラックの属性・リンク）は、キーと op を足すまで画面に出さない**（21.6）。
7. **確定するまで書き換えない。何でも取り消せる。** トリム・ドラッグ・AI の提案は、確定するまで影で見せるだけ。確定した操作は 1 つの op（またはバッチ）として .mzc に書き、Ctrl+Z の 1 回で取り消せる。断られた操作は、その場で理由を出して元の位置へ戻る。削除の前に確認は出さず、状態の帯に結果の 1 文と［取り消す］を出す（通知にはしない。14.1）。
8. **人には名前、機械には ID。どちらにもわかる二つの形。** 見出しは名前、ID は札とツールチップで必ず引ける。操作・履歴・診断・提案は、どれも「日本語の 1 文」と「op の文 / JSON」の二つの形を持ち、どの画面でも切り替えてコピーできる。
9. **どこでも同じ結果。** プレビューと書き出しは同じ画素（CPU と GPU で同じ結果）。フォントは同梱し、OS で UI の見た目も書き出しの文字も変わらない。

## 2. 作業画面の配置

### 2.1 既定の「編集」（1440×900 の論理 px）

見本: [mockups/edit.html](mockups/edit.html)

```
┌ 上の帯 40 ────────────────────────────────────────────────────────────┐
│ ロゴ メニュー｜プロジェクト / シーケンス ●保存済み │ [カット編集|色|音|出力] │ 検索 Ctrl+K ↶ ↷ ⛶ [書き出す…] │
├──┬──────────┬────────────────────────────┬─────────────┤
│レ│ 左の欄    │ モニター（プログラム / ソース のタブ）   │ 右の列        │ 上の段
│ー│ 260      │ 映像のまわり bg.viewer                 │ 320          │ 本体の 56%
│ル│          │ 再生の帯 40                            │ インスペクタ   │
│56│          │                                        │ ／履歴／AI    │
├──┴──────────┴────────────────────────────┴─────────────┤ 境目（ドラッグ）
│ タイムラインの帯 36 ／ ルーラー 26 ／ トラック（見出し 176）／ 横スクロール 12 │メーター 40│ 本体の 44%
├──────────────────────────────────────────────────────────────┤
│ 状態の帯 24                                                                    │
└──────────────────────────────────────────────────────────────┘
```

| 領域 | 既定 | 最小 | 最大 | 畳んだとき |
|---|---|---|---|---|
| 上の帯 | 高さ 40 | — | — | 畳まない（集中モードでだけ隠す） |
| レール | 幅 56（アイコン 20 ＋ 11px のラベル。4 文字まで） | — | — | 畳まない |
| 左の欄 | 幅 260 | 220 | 420 | 幅 0。レールの選ばれているアイコンをもう一度押すと閉じる |
| モニター | 残り | 400×260 | — | — |
| 右の列 | 幅 320 | 280 | 440 | 幅 0。`view.rightColumn`（Ctrl+Alt+\）で開閉。インスペクタのキー（Ctrl+Alt+I）は 3.10 のトグル |
| タイムライン | 本体の 44% | 高さ 200 | 本体の 75% | — |
| メーター | 幅 40（タイムラインの右。2 本の帯と、帯の右に dB の数字） | — | — | 設定で隠せる（既定は出す） |
| 状態の帯 | 高さ 24 | — | — | 畳まない |

- 境目をダブルクリックすると既定の大きさに戻る。大きさはワークスペースごとに自動で覚える。
- 窓の最小は 1024×640。最小の大きさに足りないときは、左の欄 → 右の列の順に畳み、レールや上の帯のボタンから「重ねて開く」形にする（重ねて開いたものは Esc か外のクリックで閉じる）。これは窓の大きさが変わったときだけ起き、操作では起きない。見本は [mockups/edit.html?w=1024](mockups/edit.html)。
- **上の帯の幅が足りないとき**は、次の順に縮める: ① メニューの 7 語を ≡ の 1 つにまとめる ② 検索の欄を虫眼鏡のボタンだけにする（Ctrl+K は同じ）③ 「✦ AI」の札を印だけにする ④ プロジェクト名を末尾の「…」で省く。ワークスペースの切り替え・↶ ↷・集中モード・［書き出す…］は、位置も大きさも変えない。
- **状態の帯の幅が足りないとき**は、右の項目を次の順に隠す: ① 再生の fps ② 実行先 ③ シーケンスの形式 ④ 自動保存。問題の件数と AI に見せている印は隠さない。左の 1 文は末尾を「…」で省き、［取り消す］は残す。
- 4K など広い窓では、左の欄と右の列は既定の幅のまま広げず、増えた分をモニターとタイムラインに回す。

### 2.2 モニターは 1 つか 2 つか

- **窓の幅が 1600 以上なら、ソースとプログラムの 2 つを並べる。1600 未満なら 1 つで、タブ（プログラム / ソース）で切り替える。** 設定の「モニター: 自動 / 1 つ / 2 つ」で固定できる（Shift+2 でも切り替え）。
  - 理由: 3 点編集をする人はソースとプログラムを同時に見たい（pro）。1440 幅では、モニターの領域（1440 − 56 − 260 − 320 = 804）を 2 つに分けると 1 つが約 400px になり、16:9 の絵の高さが 225px しか取れず、モニターの最小 400×260 を守れない。プレビューの描画は表示中のモニターだけ行うので、1 つのときは負荷も下がる（implement）。見本は [mockups/edit.html?w=1920](mockups/edit.html)。
- 1 つのときの「ソース」タブは、見出しの帯を素材の種類の色の 2px の線で縁取り、左上に「ソース: 素材名」と出す（いまどちらを見ているかを見失わないように）。
- 素材をダブルクリックするとソースのタブで開く。, / . で入れたあとは、自動ではプログラムに戻さない（勝手に変えない）。設定「入れたらプログラムに戻す」で選べる。

### 2.3 ワークスペース

上の帯の中央で切り替える（Alt+1〜4）。

| 名前 | 中身 |
|---|---|
| カット編集（既定） | 2.1 のとおり。メニューの「編集」と区別するため「カット編集」と呼ぶ |
| 色 | 左の欄は効果（色の分類）、右の列は色の項目、モニターの下にスコープ（波形・ベクトル）の帯 |
| 音 | 左の欄は音、右の列は音量・パン、メーターを幅 96 のミキサーに広げる。トラックの高さを「大」にする |
| 出力 | 10 章の画面（書き出しの設定・確認・待ち行列） |

- **上の帯はどのワークスペースでも同じ部品を同じ位置に置く。** 出力のワークスペースでは［書き出す…］を無効にするだけで、消したり動かしたりしない（ツールチップ「いま出力のワークスペースにいます」）。
- **［書き出す…］は出力のワークスペースへの近道**（Ctrl+M）。「…」は、押すと画面が開くだけで、まだ書き出しは始まらないことを示す。書き出しを始めるのは、出力の画面の［書き出す］（「…」なし）だけ。

- どのワークスペースにも［既定に戻す］（`表示 → 配置を既定に戻す`、Ctrl+Alt+0）。
- **集中モード（Ctrl+Shift+F）:** 上の帯・左の欄・右の列を畳み、モニターとタイムラインだけにする。もう一度押すと戻る。人が押したときだけ変わる。
- **ポインターの下のパネルを最大化（Ctrl+Shift+Enter）:** JIS 配列では ` の位置に半角／全角キーがあるので、Premiere の ` は既定にしない（Premiere 互換の配列では ` も割り当てる。物理キーで判定する）。
- 配置（6 つの領域の幅・高さ・表示と非表示、モニターの数、右の列のタブ）は利用者の設定の JSON に保存し、起動のたびに戻す。モニターが減っていたら、窓を見える場所に戻す。
- 自由なドッキング・パネルの移動・フローティングの窓は M3 以降（21.8）。2 つ目のディスプレイへのプログラムモニターの全画面出力は M2。

## 3. パネルの仕様

### 3.1 一覧

| パネル | 場所 | 目的 |
|---|---|---|
| 上の帯 | 上 | プロジェクト名・保存の状態・ワークスペース・コマンドパレットの入口・取り消し・集中モード・書き出す… |
| レール | 左端 | 左の欄の切り替え（素材・効果・文字・音・テキスト・問題・設定） |
| 素材 | 左の欄 | 素材の一覧（8 章） |
| 効果 | 左の欄 | 効果（プラグイン）の一覧 |
| 文字 | 左の欄 | 字幕・テロップの追加と型 |
| 音 | 左の欄 | 音の素材と音の効果 |
| テキスト | 左の欄 | .mzc の本文（行番号つき）。「ソース」とは呼ばない（「ソース」はソースモニターとソースのパッチだけ） |
| 問題 | 左の欄 | 診断の一覧 |
| モニター | 上の中央 | プログラム・ソース（9 章）。トリム中はプログラムのタブの中身がトリムの表示になる（6 章） |
| 右の列 | 右 | タブで インスペクタ ／ 履歴 ／ AI |
| タイムライン | 下 | 編集（4 章） |
| メーター | タイムラインの右 | 音の大きさ |
| 状態の帯 | 最下段 | 直前の操作の結果・診断の件数・実行先・形式・保存 |
| コマンドパレット | 上の中央に重ねる | すべてのコマンドを探して実行。op の文をそのまま打てる |

### 3.2 上の帯（高さ 40）

- **中身（左から）:** ロゴ（16px の印）→ メニュー（ファイル・編集・クリップ・シーケンス・マーカー・表示・ヘルプ）→ 「プロジェクト名 / シーケンス名」（13px。シーケンス名は押すと切り替えの一覧）→ 保存の状態 → 中央にワークスペースの切り替え → 右に「✦ AI」の札・検索の欄（「コマンドを探す… Ctrl+K」）・↶ ↷・集中モード・［書き出す…］（主のボタン。Ctrl+M。2.3）。
- **メニューの開き方（`menu.open`）:** Alt を**単独で**押して離したときだけメニューに入る。押してから離すまでに、ほかのキー・クリック・ホイール・ドラッグが 1 つでもあったら入らない（Alt+ドラッグ・Alt+ホイール・Alt+C のあとでフォーカスがメニューへ飛ばない）。標準と Premiere 互換では F10 でも開く。**Resolve 互換では F10 を上書き（`edit.overwrite`）に使うので、メニューは Alt だけ**で開き、割り当ての画面の F10 の刻印も配列に合わせて「上書き」にする。macOS では OS のメニューバーを使わず、同じ規則で窓の中のメニューを開く。
- **保存の状態:** 「● 保存済み」（`ok`）／「◌ 保存しています」（300ms を超えたときだけ）／「● 保存できませんでした」（`error`。押すと原因と対処）。外のエディタが開いているあいだは「外で変更あり」（`textSource`）が一瞬出る。
- **AI の状態:** AI が接続されているときだけ、検索の欄の左に「✦ AI」の小さな札。考えている間は点が 1.2 秒周期でゆっくり明滅（「動きを減らす」では明滅しない）。
- ↶ ↷ は無効のとき、ツールチップで理由（「取り消せる操作がありません」）を言う。

### 3.3 レール（幅 56）

- 上から: 素材・効果・文字・音・テキスト・問題。下の端に設定。アイコン 20px の下に 11px のラベル（「素材」など。和文 11px はここだけの例外で、4 文字までの短い語に限る）。設定「レールのラベルを隠す」で幅 44 にできる。
- **問題のアイコンは常にある。** 0 件のときは灰色、1 件以上で件数の札（エラーは `error`、警告だけなら `warn`）。出たり消えたりしない。
- 選ばれているアイコンの左に 2px の `accent` の線。押すと左の欄が切り替わり、選ばれているものをもう一度押すと左の欄を閉じる。

### 3.4 素材

8 章。

### 3.5 効果

- **目的:** 効果（組み込みのプラグインと wasm の `.mzplug`）を探して、選んだクリップに足す。
- **中身:** 検索、分類の札（すべて・色・ぼかし・変形・様式・音）、一覧。一覧の各行は、名前（日本語）・.mzc のキー（等幅 11px、`text-3`）・出どころの札（`組み込み` / `wasm` / `GPU 対応`）。行を選ぶと、下に `@effect` の説明と、引数（`@param` の名前・範囲・既定値）を出す。
- schema（`schemaJson()` の `effects`）から自動で作る。手で書いた一覧は持たない。
- **操作:** ダブルクリックか Enter で、選んだクリップに足す（`set <id> <key>=<既定値>`）。クリップへのドラッグでも足せる。クリップを選んでいないときは、行の右の［足す］を無効にし、ツールチップで「クリップを選ぶと足せます」。
- **状態:** 宣言に誤りのある包みは、一覧の最後に「読み込めなかった効果」として赤のアイコンと `bad-plugin` の札で出し、問題の欄にも出す。wasm の詳しい情報には「ファイルとネットワークに触れません」と書く。

### 3.6 文字（字幕とテロップ）

- **目的:** 字幕とテロップを、AI なしでも迷わず付けられるようにする（初めての人の最初の 10 分の山場）。
- **中身:** 上に主のボタン［字幕を追加］（Shift+T）、その下に「SRT を読み込む…」「SRT に書き出す…」。その下に型（下 3 分の 1・中央のタイトル・名前と肩書き・エンドロール）の縮小画像の格子。
- **字幕の流れ:**
  1. ［字幕を追加］を押すと、字幕のトラック（なければ作る。名前「字幕」、文字のトラックの最上段）の再生ヘッドの位置に、長さ 3 秒の字幕のクリップを置き、プログラムモニターの上の字幕の位置に入力の欄を開く（op は `add text "" at=<再生ヘッド> dur=3 track=<字幕のトラック>`）。
  2. その場で打つ。IME の変換中の文字は、入力の欄の中に下線つきで出す（UM 側に「変換中の文字」のイベントが要る。21.5）。
  3. **変換中の文字がないときの Enter** で確定し、次の字幕を前の字幕の終わりに置いて、入力を続ける。**変換中の文字があるあいだの Enter は IME に渡す**（変換の確定にだけ使い、字幕は確定しない）。Shift+Enter は改行。Esc は、変換中なら変換の取り消し、そうでなければ入力を終える。同じ規則を文字の欄すべて（AI の入力・名前の変更・テキストの欄）に使う。
  4. 長さは、クリップの端のドラッグか、Q / W（再生ヘッドまで詰める）で合わせる。
- 1 行が長すぎるとき（既定は 1 行 16 字、2 行まで）は、警告の札「1 行が 21 字です」と［2 行に分ける］。
- 型の縮小画像をドラッグしてタイムラインに置ける。

### 3.7 音

- 音の素材（素材の欄のうち音だけを絞り込んだもの）と、音の効果（音量・EQ・ノイズの軽減など、schema の `kinds` に audio を持つもの）。

### 3.8 テキスト（.mzc の本文）

- **目的:** 「画面とテキストが同じもの」であることを、いちばん直接に見せる。
- **中身:** 行番号つきの .mzc（等幅 12px）。キーは `accent-hover`、文字列は `textSource`（生成り色）、注釈は `text-3`。選んだクリップの行を `accent.tint` で塗り、タイムラインと双方向に同じものを選ぶ。
- **状態:**
  - 操作のたびに、変わった行を 600ms だけ強調する（`changes[]` の `edit` は黄の左の線、`insert` は緑、`comment` は灰）。
  - 注釈にした（消した）クリップの行は薄く出し、右に［戻す］（その行の注釈を外す操作。「戻す」はここだけで使う。16.2）。
  - 外のエディタで書き換えたら、見出しの下に「外で変更されました。読み直しました（3 行）」と出す。エラーのある書き換えのあいだは「テキストにエラー 1 · 前の状態を表示中」と出し、エラーの行に赤の波線。
- **操作:** M1 は読むだけ（選択・コピー・行へ飛ぶ）。編集できるようにするのは M2（文字の欄の部品、IME、クリップボードがそろってから）。Ctrl+E（`text.reveal`、［テキストで開く］）で、選んだクリップの行を開く。

### 3.9 問題（診断）

- **中身:** 1 件 1 行。重さのアイコン（エラーは丸に ×、警告は三角）、原因コードの札（`unknown-key`。等幅 11px）、日本語の理由、ヒント、場所（`本編_v3.mzc:7:12`。押すとテキストの欄のその列へ）。`suggest` があれば［'color' に直す］（それ自体が op。履歴に「人」として積む）。
- 問題のあるクリップは、タイムラインのクリップの右上に重さのアイコン。仮の位置（`placed=false`）は白の斜線（右下がり）と「仮の位置」の文字。
- **重さの決まり:** `missing-source`（素材がない）は**エラー**（書き出しを止める。10 章）。どの画面（レールの札・状態の帯・スタート画面の台帳の札・書き出しの前の確認）でも同じ重さで出す。
- **空:** 緑のチェックと「問題はありません」。

### 3.10 右の列（インスペクタ ／ 履歴 ／ AI）

- タブの帯（高さ 32）: インスペクタ（Ctrl+Alt+I）・履歴（Ctrl+Alt+H）・AI（Ctrl+J。件数の紫の札）。
- **タブのキーはトグル:** そのタブが出ていなければ（右の列が畳まれているときは開いて）そのタブにする。そのタブが出ていれば右の列を畳む。右の列の開閉だけをしたいときは `view.rightColumn`（Ctrl+Alt+\）。2.1・5.4 も同じ規則。
- タブは人が選ぶ。例外は 2 つだけで、どれも**同じ列の中身**が替わるだけ（配置は変わらない）:
  - トリムを始めたとき、インスペクタのタブにする（トリムの中身を出すため）。終わったら元のタブに戻す。
  - AI の提案の［確認する］を押したとき、AI のタブにする。
- インスペクタは 7 章、履歴は 14 章、AI は 15 章。

4 章。

### 3.12 メーター（幅 40）

- 2 本の縦の帯（L・R、各 5px）と、帯の右に目盛りの数字。目盛りは −60・−18・−6・0 dBFS で、数字は 11px（`fs.xs`。英数字なので可）で帯の外に出す（色だけに頼らない）。縦の位置は dB に比例し、色の境目は目盛りの −18 と −6 の位置から計算する（`meter.low` → `meter.mid` → `meter.high`）。ピークの線を 1.5 秒保つ。0 を超えたら上の端に赤の四角を出し、押すまで残す。

### 3.13 状態の帯（高さ 24）

- **左:** 直前の操作の結果の 1 文と［取り消す（Ctrl+Z）］（14.1）。トリム中・ドラッグ中は「トリム中: まだファイルは書き換えていません」。
- **右（右から）:** 自動保存 ／ シーケンスの形式（`1920×1080 · 29.97p · 48kHz`）／ 実行先（`GPU（wgpu）` または `CPU 16 コア`）／ 再生の fps（再生中だけ。コマを飛ばしたら「コマ落ち 3」）／ 問題の件数（「エラー 1 · 警告 2」。エラーがあれば丸に × のアイコン、警告だけなら三角。押すと問題の欄）／ AI に見せている印（紫の小さな目。15.3）。
- 幅が足りないときに隠す順は 2.1。
- 書き出しの最中は、中央に「書き出し中 42% · 残り 1:12」と細い進み具合の帯。

### 3.14 コマンドパレット（Ctrl+K）

- 上の中央に幅 560 で重ねる。すべてのコマンドを、日本語の名前・英語の名前・コマンドの ID で探して実行する。各行に名前・キーの札・分類。
- **op の文をそのまま打てる**（`split int_b2 42.5`、`move title clip_a.start+1.5`）。打つときは文法が受け付ける形ならどれでもよく、画面に出し直すとき（履歴・提案・トリムの欄）は 4.7 の正規の形（秒、コマの境目、6 桁）にする。打っている間に schema から候補を出し、下に dry-run の結果を 1 行出す（「int_b2 を 00:00:42:15 で 2 つに分けます。ID は int_b2_2」・動くクリップの数・エラーの増加）。Enter で実行。エラーが増えるなら Enter を無効にして理由を出す。
- コマンドは日本語の名前・英語の名前・ID のほかに、**ほかのソフトの呼び方の別名**でも引ける（例: 「レーザー」「カミソリ」→ ブレード、「リフト」→ 削除（隙間を残す）、「抽出」「エクストラクト」→ イン〜アウトを詰めて削除、「フレーム」→ コマ）。別名は i18n の表に `alias.*` として持つ。
- 「人が使うコマンドと AI が使うコマンドは同じ」ということを、利用者に見せる一番の窓口。

## 4. タイムライン

見本: [mockups/edit.html](mockups/edit.html)、[mockups/trim.html](mockups/trim.html)

### 4.1 タイムラインの帯（高さ 36）

- **左から:** 現在の時刻（幅 176 でトラックの見出しと揃える。等幅 18px）→ ツール（選択 V ／ トリム T ／ ブレード B）→ スナップ（N）・リンクした選択（Ctrl+Shift+L）・参照の線（Ctrl+Shift+R）→ **文脈の操作の欄** → 右寄せで、ズームのスライダーと［全体］（Shift+Z）。
- **文脈の操作の欄**（選んだものの名前と、それに効く操作 3〜5 個。キーの札つき）:
  - クリップを選んでいる: `分割 Ctrl+B` ／ `■桃 削除（隙間を残す） Delete` ／ `■黄 詰めて削除 Shift+Delete` ／ `速度 Ctrl+R`（速度は .mzc に `speed=` を足してから出す。21.6）
  - 編集点を選んでいる（トリム中）: 黄の帯「リップル · A 側を短くしています · 後ろが詰まります ｜ Enter 確定 · Esc やめる」
  - 何も選んでいない: 「クリップを選ぶと、ここに操作が出ます」（`text-3`）
- 現在の時刻を押すと入力の欄になる。`1:02:10`、`+10`（10 コマ後ろ）、`-1:00`（1 秒前）、`00:01:02:10` を受け付ける。
- 幅が足りないときは、文脈の操作の欄の「選んだものの名前」を先に隠し、次に右の操作から 1 つずつ隠す（隠したものは「…」のメニューに入れる）。

### 4.2 ルーラー（高さ 26）

- 1 秒（拡大すればコマ）ごとに短い線、5 秒ごとに中の線、ラベルの位置に長い線とタイムコード（11px 等幅）。ラベルの間隔が 90px 以上空くように、拡大率で刻み（1 コマ・5 コマ・1 秒・2 秒・5 秒・10 秒・30 秒・1 分…）を選ぶ。
- **イン〜アウト:** ルーラーに `inOut` の帯と両端の 2px の線、トラックの領域にも `inOutLane`。
- **マーカー:** 9×11 の五角形。色はラベルの色。ホバーで名前、ダブルクリックで編集。AI が付けたマーカーは紫の点線の枠（人が［受け入れる］まで）。
- **再生ヘッド:** `playhead` の 1px の線の両側に `playheadEdge`（黒）の 1px の縁（クリップの面の上でも見失わないように。赤だけでは映像の面に対して 2.9:1 しかない）と、13×14 のつまみ。ルーラーのクリックでジャンプ、ドラッグでスクラブ。
- プロジェクトの終わりより後ろは `pastEnd` で暗くする。

### 4.3 トラックの見出し（幅 176）

- **映像:** `[V1]` の札・名前・目（表示）・鍵（ロック）。**音:** `[A1]` の札・名前・M・S・鍵。トリムのときだけ、鍵の左に同期ロック（縦の 2 本線と錠前のアイコン。リンクの鎖とは別の形）を出す。
- **`[V1]` の札はソースのパッチとターゲットを一つにまとめたもの。** 青く塗るとターゲットになり、挿入・上書き・貼り付け・分割の行き先になる。設定「ソースのパッチを別に扱う」をオンにすると、札の左に小さなパッチの列が現れる（Premiere の初心者のつまずきを避ける）。
- **番号は 1 から。** 映像は V1（いちばん下）から上へ、音は A1（いちばん上）から下へ。V1 と A1 が 4px の溝をはさんで向かい合う。
  - .mzc の `track=` はいま 0 から数える。**画面・show・ai.md・診断の文をまとめて「V1 / A1」にそろえる**ことを提案する（`track=V1` の書き方を足し、`track=0` は互換の別名として残す）。そろうまでは、画面は表示の層で +1 して V1 と出し、文では「V1（.mzc の track=0）」と書く。画面だけの表記を勝手に作らない。
- **ロック:** 斜めの縞（白 2.5%）を敷き、クリップの不透明度を 75%、鍵を塗りの版に。**ソロ:** S を `text.1` の塗りに黒の文字（意味の色は使わない）。**ミュート:** M をグレーの塗りにし、波形を薄く。
- **高さ:** 小 28 ／ やや小 40 ／ 中 52 ／ 大 64 ／ 特大 96 の 5 つ（tokens.json の `trackHeight.presets`）。既定は V1 と**すべての音のトラック**が 52（音量の線と波形をいつも出せるように）、ほかの映像と文字のトラックは 40。見出しの下の端のドラッグで 1 本ずつ、Shift+= / Shift+- で映像を、Ctrl+Shift+= / Ctrl+Shift+- で音をまとめて変える。
- 映像と音は別々に縦にスクロールし、溝の位置は固定する。

### 4.4 クリップ

| 要素 | 決まり |
|---|---|
| 形 | 角丸 3、上下に 2px の余白。面は `clip.<種類>.face`、上の辺に 2px の `clip.<種類>.mark` |
| 見出し | 左上（6, 4）に 12px の**表示名**。表示名は .mzc の `name=`（21.6 で足す）、なければ素材名か文字の中身。収まらなければ末尾を「…」で省く。**左端が画面の外にあるときは、見えている左端に名前を寄せる（sticky）** |
| ID | 見出しには出さない。ツールチップ「インタビュー_店主_A.mp4 · ID int_a3 · 23 行目」、インスペクタの札、右クリックの「ID をコピー」。表示メニュー「ID を見出しに出す」をオンにすると、名前の後ろに等幅 11px の `clip.subText` で出す（AI と一緒に作業するとき用。面の上で 7.7:1 以上） |
| 種類 | 色だけで示さない。映像は左端に縮小画像（幅 46）、音は波形、文字は名前の前に T のアイコン、静止画は四角のアイコン、色は塗りの四角 |
| 札（見出しの右） | `fx`（効果あり）、`50%`（速度）、`−18 dB`（音量）、鎖（リンク）、矢印つきの鎖（参照で置いたもの。水色）。等幅 11px、`clip.tagBg` の地に `clip.subText` の文字。札に色を付けるのは「同期のずれ」（error）とトリムで動いた量（ripple の地）だけで、文字の頭（+ や −）で色を決めない |
| ラベル | 左の辺の 3px にラベルの色（上の辺は種類の印だけに使う。位置で分ける） |
| 縮小画像 | 高さ 40 以上のトラックで。なし ／ 先頭だけ（既定） ／ 先頭と末尾 ／ 連続 |
| 波形 | 面の中に `clip.audio.wave` の色で（面と選んだ面の両方に 3:1 以上）。高さ 36 未満では描かない。音量の線を変えると波形の大きさも変わる |
| 音量・不透明度の線 | `volumeLine`（白 70%）の 1px。クリップの高さが 40 以上のとき、ホバーで出す（Ctrl+Shift+K で常に）。上下のドラッグで値、Ctrl+クリックでキーフレーム（キーフレームの書き方を足してから。21.6） |
| フェード | 上の角に直径 8 の白いつまみ（ホバーで出す）。ドラッグで長さ。フェードの部分は黒 38% の三角と白の斜めの線（いまの「下の端の暗い帯」はやめる） |
| リンク | 名前に下線。同期がずれたら `error` の札「⊗ +3」（丸に × とずれたコマ数）と `error` の 1px の枠。右クリックの「同期を直す」 |
| 選択 | `selection.clipInner`（白）2px の枠（内側）＋外に `selection.clipOuter`（黒）1px、面は `faceSelected`。色を明るくするだけの見せ方はしない（ほかの選択は accent。17.1） |
| 同じトラックで重なった | 重なった範囲は、それぞれの高さを半分にして上下に分けて描く（`show` と同じ見え方）。重なりの範囲に × の細い帯 |
| 仮の位置（`placed=false`） | `hatchNeutral`（白 25%）の右下がりの斜線＋⚠＋「仮の位置」。ツールチップに原因コード（意味の色は割り当てない） |
| オフライン | `error` の 25% の右上がりの斜線＋丸に ×＋「素材がありません · 素材名」（斜線の向きでも仮の位置と分ける） |
| 無効（出力しない） | 面を 40% にし、名前に取り消し線 |
| 注釈にした（消した） | タイムラインでは隠す。テキストの欄で薄く出して［戻す］ |

- クリップの上の文字の色は、面の色の輝度から白か黒を自動で選ぶ（4.5:1 以上になる方）。既定の面はどれも白い文字で 7:1 以上。
- 同じ素材を何度も使う編集（インタビュー_A が 3 回並ぶ）では、表示名を付けて見出しで区別できるようにする（F2。5.4）。

### 4.5 参照の見せ方

- `at=` で参照しているクリップには水色の札（矢印つきの鎖のアイコン）。クリップを選ぶと、**参照先の端から参照している側の端へ点線の矢印**（`reference`、1px、点線 3-2）と、ずれの札（`+1.5 秒`）を描く。帯の鎖のボタン（Ctrl+Shift+R）で常に出す・出さないを切り替える。
- ドラッグで参照が秒に変わるときは、ポインターの横に「参照を外して 00:00:03:06 に置きます · R で参照を保つ」と出す。**ドラッグ中に R を押すと**、そのドラッグの間だけ参照を保つ（`move pip clip_a.start+0.5`）。修飾キーの意味は 4.8 の表にまとめる。
- インスペクタの「開始」は、参照なら札（`🔗 clip_a の始まり ＋ 1.5 秒`）で出す（7.3）。

### 4.6 ズーム・スクロール・スナップ・ドラッグ

- **ズーム:** `=` / `-`（中心は再生ヘッド）、Alt+ホイール（中心はポインター）、ズームのスライダー、横スクロールの帯の両端のつまみ。Shift+Z（`\` も。JIS では「]」の位置）で全体。
- **全体に合わせる:** 手で拡大縮小するまで、全体が見えるように自動で合わせる（いまの `fitZoom` の動きを残す）。トリムに入っても拡大率は変えない（変えたいときは人が `=` を押す）。
- **スナップ（N）:** 吸い付いた瞬間に、吸い付いた先に白 1px の縦線を全トラックに通し、上に小さな三角を 300ms 出す。吸い付く先は、編集点・再生ヘッド・マーカー・イン・アウト・0。**ドラッグ中にスナップのキー（標準 N ／ Premiere 互換 S）を押すと、そのドラッグの間だけスナップを逆にする**（Premiere と同じ。離したら元に戻る）。Alt はスナップに使わない。
- **ドラッグで動かす:** 既定は上書き（詰めない。落とす範囲を `overwriteTint` で塗る）。Ctrl を押している間は挿入（後ろを押す。挿入の位置に `ripple` の 2px の線と ▶▶）。Ctrl+Alt を押してから始めたドラッグは入れ替え（スナップは N の規則のまま）。Alt を押してから始めたドラッグは複製。Esc で取りやめ。つかんだ物は不透明度 65%。落とせない場所ではカーソルを「禁止」に。
- **端のドラッグ:** 選択ツールでは上書きのトリム（詰めない）、Ctrl を押している間はリップル（詰める）。**Alt を押してから端をつかむと、リンクした映像と音の片方だけ**をトリムする（J カット・L カット。Premiere と同じ）。op は片方のクリップへの `trim`（5.2）。
- **ドラッグ中のプレビュー:** 画質を 1/4 に落とす。離したら正しく描く。

### 4.7 時刻（コマへの量子化）

- 画面の時刻は **タイムコード `HH:MM:SS:FF`**（ドロップフレームは `;`）が既定。設定で「秒（3.50 秒）」「フレーム数」に切り替えられる。HH:MM:SS:FF のときは、ツールチップに「時:分:秒:コマ」と出す。数字は等幅。
- **編集で決まる時刻は、すべてシーケンスのコマの境目に量子化する。** 内部では「コマの番号（整数）＋ fps（有理数。29.97 は 30000/1001）」で持つ。
  - op の文は今の文法のとおり秒で書く。値は「コマの境目の秒」を小数 6 桁で書き（例: 29.97p の 6 コマは `0.200200`、30p の 24.2 秒は `24.200000`）、読むときは一番近いコマの境目に丸める。だから「画面に +6 コマと出たのに、ファイルは 5.994 コマ」は起きない。画面・提案・履歴・トリムの欄が出す op の文はすべてこの正規の形にする（分:秒や桁の少ない書き方を混ぜない）。
  - 「画面の表示 → op の文 → .mzc → 読み直し → 画面の表示」で値が変わらないことを、fps ごと（24・25・29.97・30・50・59.94・60）にテストで確かめる。
  - .mzc にコマやタイムコードの書き方（`12f`、`00:00:42:15`）を足すときは、文法・`schemaJson()` の `syntax`・ai.md・show を**同時に**直す。画面だけの書き方は作らない。
- **人向けの 1 文の時刻**は、設定の時刻の表示（既定はタイムコード `00:00:24:06`）で出す。**長さ**は「0.80 秒（24 コマ）」の形にそろえる。op の文だけは文法どおりの秒で、等幅の `text-2` で人向けの文と見分けられるように出す。

### 4.8 修飾キーの表

修飾キーの意味は場面ごとに 1 つ。ドラッグを「始める前に押していた」か「始めてから押した」かで意味を変えるのは、複製（Alt）だけにする（Premiere と Resolve の両方の慣習）。

## 5. 編集ツールとキー

### 5.1 ツール

- **ツールは 3 つ:** 選択（V）、トリム（T）、ブレード（B）。手のひらは H（Space は再生）。「ブレード」は Resolve の呼び方で、Premiere の「レーザー」もコマンドパレットの別名で引ける（3.14）。
- **トリム（T）は Resolve 型:** ポインターの位置で動作が変わる。編集点の端はリップル、編集点の真ん中はロール、クリップの上の段はスリップ、下の段はスライド。Premiere 互換の配列では、B（リップル）・N（ロール）・Y（スリップ）・U（スライド）で動作を固定したトリムになる（同じコマンド `trim.mode.*` を呼ぶ）。
- **選択ツールのまま:** クリップの端のドラッグは上書きのトリム（カーソル `⟷`）。Ctrl を押しながらならリップル（黄のカーソル `]⟶`）。
  - **端を押してドラッグ:** その場でトリムし、離したときに 1 つの op として書く。ドラッグの間は、状態の帯に「トリム中」、プログラムのタブに「トリム中」の札、モニターに A/B の並べ表示を出す（6 章と同じ見え方。インスペクタの中身は替えない）。
  - **端を押して離す（クリック）:** その編集点を選んでトリムモードに入る（6 章。インスペクタの中身もトリムに替わる）。
- **いまのモードを必ず見せる:** ツールの札の下の線（トリムは黄）、カーソルの形、文脈の操作の欄、状態の帯の「トリム中」。カーソルの形が UM でそろうまでは、ポインターの右下に 16px のモードの印を自分で描いて代わりにする。

### 5.2 すべての編集コマンドと op の対応

いまの .mzc では、`at=` のないクリップは同じトラックの前のクリップの後ろに並ぶ（だから `delete` と `trim` は後ろを押したり詰めたりする）。**後ろを動かさない操作は、後ろの `at=` のないクリップに今の秒の `at=` を書くバッチになる**（以下「後ろを固定」）。どのコマンドも 1 つの op か 1 つのバッチで、Ctrl+Z の 1 回で取り消せる。

### 5.3 キーの判定

- **キーは物理キー（スキャンコード）で判定する。** 文字の入力の欄にフォーカスがないときは IME を止める（`SDL_StopTextInput`）。これで、日本語の IME がオンでもショートカットが効く。これを受け入れの条件にする（UM の `Key` にスキャンコードを足す必要がある。21.5）。
- Mac では Ctrl を Cmd に、Alt を Option に読み替える。**macOS ではファンクションキー（F11 のデスクトップの表示、F12 など）を OS が使うことが多い。** 割り当ての画面で「この組み合わせは macOS が使っている可能性があります」と警告し、代わりのキー（例: 置き換えは Cmd+Shift+F11 の代わりに Option+R）を示す。
- キーの名前は US 配列の位置で持ち（`=` は US の = の位置）、画面の刻印は選んだ配列で出す。JIS 配列では US の `=` の位置は「^」のキーなので、拡大は「^」と表示する。**US の `\` の位置（スキャンコード BACKSLASH）は、JIS では Enter の左の「]」（む）のキー**なので、全体（`view.fit`）は「]」と表示する（JIS の「¥」と「ろ」は別のスキャンコードで、既定では何も割り当てない）。ツールチップ・メニュー・一覧のキーの表記も同じ規則にする。
- **配列のプリセット:** 「MozaicCut 標準」（既定）、「Premiere Pro 互換」、「DaVinci Resolve 互換」、「MozaicCut 0.x」（いまの割り当て。移行のために 1 版だけ残す）。最初の起動時にスタート画面で選ぶ。**どのプリセットも同じコマンドの ID を呼ぶ。**
- 割り当ての画面（Ctrl+/）: キーボードの絵（JIS / US を切り替え）の上に割り当てを出し、修飾キーを押すとその組み合わせ（なし・Ctrl・Shift・Alt・Ctrl+Shift・Ctrl+Alt・Alt+Shift）に切り替わる。キーの上には 4 文字までの短い名前（i18n の `keycap.*`。例: 前詰め・後詰め・スナップ・マーカー・リフト）を 12px で出し、正式な名前はホバーとフォーカスで出す。コマンドの名前で検索でき、衝突を警告し（［割り当てる（〜は外す）］［やめる］）、［JSON に保存する］［JSON から読み込む］ができる。見本: [mockups/shortcuts.html](mockups/shortcuts.html)
- メニューの各項目、ツールチップ、コマンドパレットには、必ずキーを並べて出す。

## 6. トリム

見本: [mockups/trim.html](mockups/trim.html)

- **入り方:** トリムツールで編集点を押す（クリック）／ 選択ツールで Ctrl を押しながら端を押して離す（クリック。押したままドラッグしたときは、その場のトリムで、離したときに書く。5.1）／ ↑↓ で編集点に移ってから T ／ 編集点をダブルクリック。
- **入ると（配置は変えない。中身だけが替わる）:**
  - **モニター:** タブは「プログラム ／ ソース」のまま増やさない。プログラムのタブの名前の横に黄の「トリム中」の札を出し、中身を「トリム」の表示にする。A 側（出ていくクリップの最後のコマ）と B 側（入ってくるクリップの最初のコマ）を並べ、動かしている側に `ripple`（ロールなら `overwrite`）の 2px の枠。各々に素材のタイムコード（アウト 00:03:12:08 ／ イン 00:03:32:12）。下に「−10 ／ −1 ／ 変化の量（等幅 22px、ローラーの色）／ +1 ／ +10」の帯。
  - **タイムライン:** 動かしている端に 4px のローラー（リップルは黄、ロールは桃。どちらも再生ヘッドの赤と色相で離れている）。動く前の位置を白の点線の影で残し、削られるコマは白の斜線（`hatchNeutral`）、動いたクリップには黄の地の「−12」の札（ロールなど詰めない動きのときは桃）。ポインターの横に、変化の量・新しいアウト・全体の長さ。ロックしたトラックには「ロック中のため動きません」と直接書く。
  - **右の列:** インスペクタのタブになり、中身はトリム専用。
    - 種類（リップル・ロール・スリップ・スライド）の 4 つのボタンとキー、動かす側（A・両側・B）
    - 変わる値（前 → 後）: 「int_b2 のアウト 00:03:12:20 → 00:03:12:08」「シーケンスの長さ 04:12:06 → 04:11:24」
    - 影響: 「後ろの 9 個が 0.40 秒（12 コマ）前へ詰まります（同期ロック）」「A3 BGM はロック中で動きません（12 コマずれます）」「テロップ 2 個は参照のまま付いて動きます」
    - **確定すると適用する操作:** op の文（`trim int_b2 end 42.100000`）と、.mzc の差分（`23 行目 - dur=12.8 + dur=12.4`）
    - ［やめる Esc］［確定する Enter］
  - **状態の帯:** 「トリム中: まだファイルは書き換えていません」。
- **確定するまでファイルは書き換えない。** Enter で 1 つの op（またはバッチ）として書き、Ctrl+Z の 1 回で取り消せる。Esc で何も書かずにトリムを抜ける。
- **拡大率は変えない。** 編集点のまわりをよく見たいときは、人が `=` を押す。抜けても元に戻すものがない（配置を動かさないので、戻すための状態を持たない）。
- J・K・L で動的トリム（再生しながら、K で止めた位置を新しい編集点にする）。`/` で編集点のまわり（前 2 秒・後ろ 2 秒）を繰り返し再生。
- 断られた場合（素材の長さを超えるなど）は、ローラーがそこで止まり、ポインターの横に吹き出し「素材の終わりです（あと 0 コマ）」。

### 7.2 見出し

- 種類のアイコン（mark の色）＋表示名（15px、600）。その下に 3 つの札:
  - 種類（`映像（video）`。日本語と行の頭の語の両方）
  - ID（`id=int_b2`。押すとコピー。ID がなければ［ID を付ける］。Shift+F2 で変える）
  - 場所（`V1 · 23 行目`。押すとテキストの欄のその行へ）
- 複数のクリップを選んだときの札は表示名（「店主インタビュー_A」）で並べ、ID はツールチップで出す。

### 7.3 項目の行（高さ 28）

- ラベル（幅 86。収まらなければ末尾を「…」で省き、ツールチップで全部を出す。左右にドラッグすると値が変わる。カーソル `⟷`。Shift で 10 倍、Ctrl で 1/10。4.8）→ 値の欄（高さ 24、等幅 12px、単位は右寄せ。押すと数字を打てる。↑↓ でも増減）→ キーフレームの ◇ → 既定に戻す ↺（既定から変わっている項目だけ）。
- 既定から変わっている項目は、ラベルの前に 5px の `accent` の点を付け、値を `accent.hover` で出す。
- **キーフレーム:** （.mzc にキーフレームの書き方を足してから。21.6）◇ を押すとアニメーションが有効になり ◆ に。キーフレームが 1 つ以上ある項目だけ、行の右に ◀ ◆ ▶ が出る。再生ヘッドの位置にキーフレームがあれば ◆ を `accent` に。クリップの下に開くキーフレームの帯（M2）で時間の上の位置を動かし、イージングは右クリックで選ぶ（直線・ゆっくり始める・ゆっくり終わる・両方）。
- **参照で決まる値:** 開始が `clip_a.start+1.5` なら、値の欄の代わりに水色（`reference`）の札（矢印つきの鎖のアイコン＋`clip_a の始まり ＋ 1.5 秒`）と、その下に `= 00:00:24:00`。札を押すと「参照で置く / 秒で置く」の切り替えと参照先の選択。人に見せる文は「clip_a の 1.5 秒後」、テキストと JSON は `clip_a.start+1.5`。
- 「参照される」: このクリップを参照しているクリップの札（押すとそのクリップへ）。

### 7.4 効果

- .mzc の行に書いた順に、番号つきで並べる。行の左のつまみのドラッグで並べ替える（`renamekey` か行の書き直し。並べ替えの op は 21.6）。
- 効果の有効・無効は、無効の行を `text-2` の文字と「無効」の文字で示す（まだ押せるので不透明度は下げない）。
- 各効果: 有効・無効のトグル、名前（日本語と .mzc のキー）、出どころの札（開いたときだけ）、節のリセット、右の ▸ で引数を開く。範囲と既定値は `@param` から。
- ［効果を足す］で、効果の一覧を検索の欄つきで重ねて出す。

### 7.5 テキストで見る（既定は開いている）

- .mzc のその行を等幅 12px（`code`。素材名などの和文が入るので 11px にはしない）で、トークンごとに出す（キーは明るい青、文字列は生成り色）。トークンの境目で折り返し、1 つのトークンが 1 行に収まらないときだけトークンの中で折る。
- **値の欄にホバー・フォーカスすると、同じトークンに下線と `accent.tint` の地。逆も同じ。** 値を変えると、そのトークンが 600ms 緑に光る。
- 見出しの右に［ID をコピー］［テキストで開く Ctrl+E］。

## 8. メディアプール（素材の欄）

- **上から:** 見出し（「素材 14」、グリッド ／ リストの切り替え、［読み込む］）→ 検索 → ビンの札（すべて・自分で作ったビン・スマートビン ⚡）→ 一覧 → 下の帯（件数・未使用の数・オフラインの数）。
- **スマートビン（最初から）:** 未使用 ／ オフライン ／ 最近の取り込み ／ AI が選んだもの（紫の札。中は AI がタグを付けた素材。開くと、なぜ選んだかを 1 文ずつ出す。人が［受け入れる］まで点線の枠）。
- **グリッド（既定）:** 2 列。縮小画像は高さ 64、角丸 3。右下に長さ（等幅 11px）、左上に札（プロキシ・オフライン）。下の端の `accent` の 3px の帯は、素材のどれだけをタイムラインで使ったか。名前は 12px で**中央を省く**（「インタビ…店主_A.mp4」。幅に収まる最長の「頭…尾」を選び、拡張子を含む尾を 1 字多めに残す。モックアップの `midEllipsis` がこの関数の見本。21.4）。
- **リスト:** 行の高さ 28。列は 種類のアイコン ／ 名前 ／ 長さ ／ 使用回数（既定）。解像度・fps・コーデック・イン・アウト・ラベル・取り込んだ日時は列の見出しの右クリックで足す。見出しを押すと並べ替え。
- **ホバースクラブ:** 縮小画像の上でポインターを動かすとコマが動く。その上で I・O を打つと素材のイン・アウト。ダブルクリックでソースのタブ（またはソースのモニター）に開く。
- **オフライン:** 斜めの縞の縮小画像と「素材がありません」と名前の取り消し線。右クリックの［場所を指定する］。同じフォルダのほかの素材もまとめて探す。プロジェクトを開いたときに 1 つでもあれば、状態の帯に「素材がありません 2 ［探す］」。
- **読み込み中:** 縮小画像の場所に薄い斜線を出し、できたら差し替える。300ms を超えたら見出しの右に「縮小画像を作っています 3/14」。モニターの上には重ねない（いまの「素材を展開しています」の表示は、ここと状態の帯に移す）。
- **ドロップ:** 素材の欄に落とせばビンに、タイムラインに落とせばその位置に入る（UM の `WindowEvent.DropFile` が位置を返す。いまの編集画面は、タイムラインに落とすとその時刻と行のトラックに置き（素材の欄にも入れる）、ほかの所に落とすと素材の欄に入れる）。
- **空:** 「素材がまだありません。ファイルをここに落とすか、［読み込む］を押してください（Ctrl+I）」＋点線の枠。

## 9. モニター

- **見出しの帯（高さ 32）:** タブ（プログラム ／ ソース。2 つのときはそれぞれの見出し。トリム中はプログラムのタブに「トリム中」の札。タブは増やさない）、表示の倍率（全体に合わせる ／ 25〜400%）、画質（全部 ／ 1/2 ／ 1/4）、重ねる表示（安全領域・グリッド・タイムコード）の切り替え、2 つに並べる（Shift+2）。

## 10. 書き出し（ワークスペース「出力」、Ctrl+M）

見本: [mockups/export.html](mockups/export.html)

- **左（幅 280）: 目的のプリセットを先に選ぶ。** YouTube 1080p（H.264）／ YouTube 4K ／ SNS 縦 1080×1920 ／ 高画質のマスター（ProRes 422 HQ）／ 音声だけ（WAV）／ 静止画（いまのコマを PNG）／ 自分のプリセット。最近の設定も上に出す。

- **右（幅 320）:**
  - 要約: ファイル名・場所・形式・解像度・フレームレート・推定のサイズ・推定の時間。元（シーケンス）と出力の比較。

## 12. 設定

- 1 つの窓の中に重ねる画面（Ctrl+,）。左に分類（一般・表示・編集・タイムライン・再生・キー・AI・書き出し・詳細）、上に検索。
- 変えるとすぐ反映する（［適用する］のボタンは置かない）。
- **強調の色は選べない（青に固定）。** 選択・フォーカスの色は意味の色のどれとも CIEDE2000 で 20 以上離す必要があり、青緑・緑・橙・紫・藍はどれも ok・reference・warn・ai のどれかとぶつかったため（tokens.json の `accent.note`）。明るいテーマと一緒に M3 で見直す。各項目に［既定に戻す］、既定から変わった項目に 5px の点。分類ごとに［この分類を既定に戻す］。
- 設定は利用者の設定の場所の JSON（`settings.json`）に保存し、人も AI も読める。プロジェクトの設定（.mzc の project 行）とは分ける。
- **主な項目:**
  - 一般: 言語（日本語 ／ English。すぐ切り替わる）、起動したら前回のプロジェクトを開く、自動保存の間隔（既定 5 分）と世代の数（既定 20）
  - 表示: UI の倍率（80〜200%、10% 刻み）、明るさ（−2〜+2 段）、読みやすさ優先の文字（BIZ UDPゴシック）、動きを減らす、レールのラベル、時刻の表示（タイムコード ／ 秒 ／ コマ数）、モニターの数（自動 ／ 1 ／ 2）、映像のまわりの色
  - 編集: ソースのパッチを別に扱う、4 点編集で長さが合わないとき、入れたらプログラムに戻す、リップルで詰まる動き（既定 140ms ／ なし）
  - タイムライン: 縮小画像（なし ／ 先頭 ／ 先頭と末尾 ／ 連続）、波形、ID を見出しに出す、既定のトラックの高さ
  - キー: 配列のプリセット、割り当ての画面を開く
  - AI: 接続（MCP）の状態、AI に見せる既定（選択・再生位置）、AI の操作を確認なしで適用（既定オフ）
  - 詳細: 実行先（自動 ／ CPU ／ GPU）、詳細の表示（fps・コマ落ち・文字のキャッシュの当たり）

## 13. 状態の見せ方

### 13.1 空

文は 2 行まで。キーの札を添える。

| 場所 | 文 |
|---|---|
| 素材 | 「素材がまだありません。ファイルをここに落とすか、［読み込む］を押してください（Ctrl+I）」 |
| タイムライン | **最初の 4 歩**（番号つき）: ① 素材を落とす ② 要らないところで切る（Ctrl+B）③ 字幕を足す（Shift+T）④ 書き出す（Ctrl+M。M1 では最小の書き出しの画面が開く。21.8）。終わった歩にはチェック。［閉じる］で隠す（設定でも） |
| インスペクタ | 「クリップを選ぶと、ここに設定が出ます」 |
| 履歴 | 「まだ操作はありません。ここに、人・AI・テキストの変更が日本語で並びます。どれも Ctrl+Z で取り消せます」 |
| 問題 | 緑のチェックと「問題はありません」 |
| AI（接続なし） | 「AI はつながっていません。つなぐと、カットや字幕の提案を受け取れます。［つなぎ方］」 |
| AI（提案なし） | 「頼みたいことを書いてください。AI は提案だけを出し、あなたが確認して適用するまでファイルは変わりません」 |

### 13.2 読み込み中

- 300ms 未満: 何も出さない。300ms〜2 秒: その場所の近くに回る印（14px、1 周 900ms）。2 秒を超えたら: 進み具合の帯・「何個中何個 · 残り時間」・［取りやめる］。
- 映像の上には重ねない。UI を止めない（展開・縮小画像・波形は裏で作る）。波形や縮小画像がまだないクリップは薄い斜線の仮の模様。

### 13.3 エラー

- 文は「事象・原因・対処」で書き、場所が足りなければ「対処 ＞ 原因 ＞ 事象」の順に残す。内部の言葉（例外の名前、関数名）を主な文にしない。詳細は［詳細］の中に、日本語の文と JSON の 2 つの形で、コピーできる。
- **断られた操作（`[out-of-range]` など）:** その場（ドラッグした所の近く）に吹き出し（`error` の 1px の枠、幅 最大 320）。1 行目に原因と対処（「素材の長さ（12.4 秒）を超えては伸ばせません。アウトを 12.4 秒以下にしてください」）、2 行目に原因コードの札と［詳細］。クリップは 160ms で元の位置へ戻り、ファイルは書き換えない。状態の帯にも同じ文。
- **.mzc の診断:** 3.9。状態の帯は件数だけ。`missing-source` はエラーとして数える。
- **外で書き換えられたとき:** 状態の帯に「外で 本編_v3.mzc が変わりました。読み直しました（3 行）」。履歴に生成り色の行（`</>` のアイコンつき）。エラーのある書き換えなら、前の状態を出し続けて、問題の欄の件数を赤くする。
- **素材を読めない:** 「clip_b.mp4 を読めませんでした。ファイルが移動したか、削除された可能性があります。［場所を指定する］」
- **モーダルのダイアログは、データが失われる操作のときだけ**（ファイルを消す、保存できない状態で閉じる）。

### 13.4 保存

- 操作のたびに保存する（いまの作り）。一時ファイルに書いてから置き換える（書いている途中で落ちても壊れない）。
- 自動保存（バックアップ）: 5 分ごとと大きな操作のあと、`<名前>.mzc.autosave/` に 20 世代。
- 上の帯に常に保存の状態（3.2）。

## 14. 取り消しと履歴

### 14.1 直前の操作の 1 文

- 操作のたびに、状態の帯の左に結果を 1 文で出す。例: 「✓ インタビュー_店主_A.mp4 を 00:00:42:00 で分割しました　取り消す（Ctrl+Z）」。動いたクリップはタイムラインで 600ms 強調する。8 秒で薄くし、次の操作まで残す。
- **操作の結果は状態の帯だけに出し、通知（トースト）にはしない。** 通知は、裏の仕事の完了（書き出し・読み込み）と、取り消せない・見落とすと困るもの（保存の失敗）だけ。削除の［取り消す］も状態の帯に置く。
- 文の中の時刻は設定の時刻の表示（既定はタイムコード）、長さは「4.40 秒（132 コマ）」の形（4.7）。

### 14.2 履歴のタブ

- 1 行の形: 書き手の印（人は無彩色の人のアイコン、AI は紫の ✦、テキストは生成り色の `</>`）／ 日本語の 1 文（13px）／ op の文（等幅 11px、`text-3`。英数字だけ）／ 時刻と［差分］［ここまで取り消す］。
- いまの位置の下に線。取り消した行は薄くし、［やり直す］を出す。
- 行にホバーすると、その操作で変わったクリップをタイムラインで光らせる（`accent` の 1px の枠、動いたクリップは白の点線）。［差分］で、その場に `- / +` の行（.mzc の差分 ／ JSON の切り替え）。
- AI の提案を適用したものは 1 行（「AI の提案（4 操作）· あなたが適用」）で、開くと中の op が並ぶ。1 回の Ctrl+Z で全部取り消せる。
- **履歴は `.mzc.history`（JSON Lines）に残し、開き直しても見られる。** AI も読める。1 行は `{"t":"2026-11-21T14:32:05+09:00","who":"human|ai|text","ops":["split int_b2 42"],"desc":"…","changes":[…]}`。いまの `EdUndo{text, desc}` に `who` と時刻を足す。
- 選択の変更と再生ヘッドの移動は履歴に積まない。

## 15. AI との協業

見本: [mockups/ai.html](mockups/ai.html)

### 15.1 原則

- **AI は書かずに「提案」する。** AI の変更は dry-run で試算を済ませた「提案」（op のまとまり）として届き、人が確認して適用するまで .mzc に 1 バイトも書かない。**機械が済ませたもの（dry-run）は「試算済み」、人がすることは「確認する」**と言葉を分ける（「確かめ済み」とは書かない。人がまだ見ていないのに確認済みと読めるため）。設定「AI の操作を確認なしで適用」は既定オフ。
- **紫 `ai` は AI だけに使う。** 選択の青・警告の橙・参照の水色と混ぜない。点線は「まだ確定していないもの」の意味にだけ使い、AI の点線は紫、参照の点線は水色、トリムの影は白で、重なっても見分けられる。
- **AI に何を見せているかを、いつも見せる。**
- **人の操作を止めない。** AI が考えている間も、人が確認している間も、人はタイムラインを触れる。ぶつかったら AI の提案の側を計算し直す。

### 15.2 流れ

1. **頼む:** 右の列の AI のタブ、下の入力の欄（Ctrl+J）。入力の欄の上に「AI に見せる」の札（`int_b2` `00:00:31:14` `イン〜アウト`）。札は × で外せ、［＋］で足せる。見せられるものは 選択・再生位置・イン〜アウト・マーカー・問題の一覧の 5 種類で、既定は選択と再生位置。見せていないものを AI が推し量ることはない。
2. **AI が考えている:** 上の帯の「✦ AI」の点が明滅し、タブに「提案を作っています…」。
3. **提案が届く:** AI のタブの上に提案のカード（紫の枠、半径 8）。中身: 「AI の提案 · 試算済み · 未確認」（ツールチップ「AI が dry-run で試算しました。ファイルにはまだ何も書いていません」）、1 文の要約、`4 操作 · 動くクリップ 11 · エラーの増加 0`、［確認する Enter］［却下する］。タブに件数の紫の札。
4. **確認する:** ［確認する］で、同じ AI のタブの中が確認の欄になる（配置は変わらない。インスペクタのタブが隠れるだけ）。
   - 上: 人の頼み（吹き出し）と、そのとき見せた文脈の札。AI の返事と 3 つの数（エラーの増加 ／ 動くクリップ ／ 全体の長さの変化「−1.43 秒（43 コマ）」）。
   - 中: **op の一覧。** 各項目にチェック・番号・日本語の 1 文（時刻はタイムコード、長さは「0.80 秒（24 コマ）」。4.7）・op の文（等幅 12px の `text-2`。正規の形 `cut 24.200000 25.000000`）・影響の札（`詰める`（黄）、`後ろの 9 個が 0.80 秒前へ`、`マーカー「サビ」と 0 コマ差`（緑）、`sub_04 の字幕が文の途中で切れます`（橙の警告））。人が外した op は、チェックを外し、文を `text-2` の取り消し線にして「外した」の札を付ける（もう一度チェックできるので不透明度は下げない）。フォーカスした項目は左に紫 2px の線と、.mzc の差分（変わったトークンだけ緑で強調）。［JSON で見る］。
   - 下: 「適用すると、履歴に『AI の提案（4 操作）』として 1 つ残り、Ctrl+Z の 1 回で取り消せます」、［選んだ 4 個を適用する Ctrl+Enter］［却下する Esc］［修正を頼む］（直してほしい点を書いて、その提案の続きとして AI に送る）。
   - **タイムライン:** 確認している間だけ、控えめに重ねる。切る範囲は紫の細い斜線（`aiTint`、左右に紫 1px）と上に `−0.80` の札。値が変わるクリップは提案の後の姿を紫の点線の影。人が外した op の範囲は灰色の点線と「外した」。札は重ならないように、近いものは 1 つにまとめる（「3 か所」）。
   - **モニター:** 「今 ／ 左右で比べる ／ 提案の後」（Alt+C）。比べるのは止まったコマ 1 枚ずつ（再生中は「提案の後」だけを描く。プレビューを 2 本同時に描かない）。音の変化は文で出す（「BGM: 今は素材の 0:45.6 ／ 提案の後は 0:58.0（サビの頭）」）。
5. **適用する:** 選んだ op だけで**新しいバッチを作り、dry-run し直してから**書く（いまのバッチは全部か無しなので、一部の適用は「選んだものだけの新しいバッチ」として作る）。エラーが増えるなら書かずに、原因の項目を赤で示す。
6. **却下する:** 提案を捨て、状態の帯に「提案を却下しました ［却下を取り消す］」（8 秒。却下した提案は 8 秒のあいだ持っておく）。

### 15.3 ぶつかりと「AI に見せる」

- 確認している間に人や外のエディタがタイムラインを変えたら、提案を新しい状態の上で dry-run し直す。結果が変わったら、カードに「計算し直しました（動くクリップ 11 → 12）」の札。当てはまらなくなった op（消したクリップへの op など）は灰色にして理由を書く。
- 「AI に見せる」がオンの間は、状態の帯の右に紫の小さな目の印。AI が話題にしたクリップの ID は返事の中で札になり、ホバーでタイムラインのそのクリップに紫の 2px の点線の枠（選択の白い実線とは色も形も別）。
- AI が「確認なしで適用」で書いている間は、上の帯の下に紫 2px の線と「✦ AI が書いています（3 / 5）」。人の操作は止めない。AI の書き込みは 1 op ずつで、人の操作が先に入ったら、AI の残りの op をその上で dry-run し直す。Esc で AI の書き込みを止める（そこまでの分は 1 回の取り消しで取り消せる）。
- AI が付けたマーカーとビンは紫の点線の枠で、人が［受け入れる］まで「AI のメモ」として扱う（書き出しには影響しない）。

### 15.4 文と JSON

- 提案・履歴・診断は「日本語の文」と「JSON」の 2 つの形を持ち、どの画面でも切り替えてコピーできる。人に見せる文は「clip_b の 1.5 秒後」、テキストと JSON は `clip_b.start+1.5`。用語は 16.2 の表を AI の文にも使う。

## 16. 文言

### 16.1 文体の決まり

- 文は「です・ます」。主語は利用者。責めない、謝りすぎない、感嘆符を使わない。
- **ボタンは動詞の終止形**（「書き出す」「作成する」「適用する」「却下する」「取り消す」「やめる」「確定する」「確認する」「復元する」）。名詞だけにしない（例外は、押すと中身を開くだけの［詳細］）。押すと画面やダイアログが開くだけのボタンは末尾に「…」（［書き出す…］［開く…］）。メニューの項目は名詞＋動詞か名詞（「分割」「削除（隙間を残す）」）でよい。
- 依頼するボタンは、だれが何をするかが分かる言い方にする（AI に直してほしい点を送るボタンは［修正を頼む］。［直す］とは書かない）。
- システムの都合の言い方を避ける（「不正な値です」ではなく「0 以上の数を入れてください」）。
- 括弧と記号: 和文の中は全角の「（）」「」。**数字と単位の間は半角の空白**（3 秒、0.80 秒、12 コマ、48 MB、−18 dB）。ただし × と % と fps の略記は詰める（1920×1080、50%、30p、48kHz）。タイムコード・ID・op の文は半角。日本語の画面でも数字は半角。数字と和文の間も半角の空白（「後ろの 9 個」）。
- 人に見せる番号は 1 から（V1、A1、1 個目）。
- 文言はすべて鍵で引く表（`i18n/ja.json`・`i18n/en.json`。鍵は `tl.delete.lift` のように場所.物.動き）に置き、画面のコードに直接書かない。英語は 1.3〜1.5 倍の長さを見込み、ボタンは文言の幅に合わせて伸びる作りにする。AI の説明の文にも同じ表を使う。

## 17. 視覚の言語

値の正本は [tokens.json](tokens.json)。部品の見本は [mockups/components.html](mockups/components.html)。

### 17.1 色

- **面と文字は R=G=B の無彩色**（いまの青みのある `#121218` などは捨てる。青みのあるグレーに囲まれると映像が黄色く見える）。`bg.0`（窓）〜`bg.4`（押下）の 5 段、文字は `text.1`〜`text.3`＋`disabled`。**`text.3` は `bg.0`〜`bg.2` の上だけで使い、`bg.3` 以上（値の欄・ホバー・押下）の上では `text.2`**（値の欄の単位・「—（混在）」・割り当てのないキーの刻印など）。
- **意味の色は 1 つに 1 つの意味:** `accent` 青（選択・フォーカス・ターゲット・アクティブなパネル・主のボタン）、`playhead` 赤（再生ヘッドだけ）、`ripple` 黄（詰める）、`overwrite` 桃（詰めない）、`ai` 紫（AI だけ）、`textSource` 生成り色（外のエディタの書き手）、`reference` 水色（参照）、`ok` 緑・`warn` 橙・`error` 赤（必ずアイコンと文を添える。エラーの赤は再生ヘッドの赤と近いので、丸に × のアイコンなしで使わない）。
  - **どの 2 つも CIEDE2000 で 20 以上離す**（19 章のテスト）。例外は playhead と error の 1 組だけで、形（黒の縁の 1px の線 ／ 丸に ×）で分ける。
  - 意味の色を別の用途に使わない: 仮の位置・削られるコマは白の斜線、ソロは `text.1` の塗り、マーカーはラベルの色、クリップの札の色は同期のずれ（error）とトリムで動いた量（ripple）だけ。
  - **選択の色:** タイムラインのクリップの選択は白（`selection.clipInner`。映像の色の判断を邪魔しないため）。そのほかのリスト・格子・カード・メニューの選択は `accent`（`selection.list`）。
  - 塗りの色の上の文字は `text.on*`（`#141414`。直接の値を書かない）。
- **クリップ:** 種類ごとに mark（上の辺の 2px と小さな印）と face（面）と faceSelected。印の色は Okabe と Ito の色を基にしている（色のクリップは、警告の橙・詰めるの黄と離すため灰）。ID と札の文字は `clip.subText`、波形は `clip.audio.wave`。
- **ラベルの 8 色:** 名前つき。利用者が付け替えられる。上の文字は輝度で黒か白。クリップでは左の辺の 3px（上の辺の種類の印と位置で分ける）。どれも `bg.1`・`bg.2` に対して 3:1 以上（マーカーに使うため）。
- **部品の輪郭:** チェック・ラジオ・オフのトグル・スライダーの溝・値の欄・検索の欄・キーの札の枠は `line.control`（`bg.0`〜`bg.3` に対して 3:1 以上）。区切りの線は `line.default` のまま。
- 設定の「明るさ」（bg・line・text.2・text.3 をまとめて −2〜+2 段）と［既定に戻す］。明るいテーマは作らない。

### 17.2 文字

- 同梱: **IBM Plex Sans JP**（Regular・SemiBold）と **IBM Plex Mono**（Regular・Medium）。予備に Noto Sans JP（素材名・字幕にある、ほかで出せない字）。設定「読みやすさ優先の文字」で BIZ UDPゴシック。どれも OFL なので、ライセンスの文を同梱する。
  - ttf.um は glyf（TrueType の輪郭）しか扱えない。同梱の前に、glyf の版であることを確かめる（CFF なら BIZ UDPゴシックに替える）。
  - UI と書き出しの既定の文字（project の `font=` がないとき）の両方に同じフォントを使い、OS で結果が変わらないようにする。
- 大きさ: `xs` 11/14（英数字だけ）、`sm` 12/16、`md` 13/18（基準）、`lg` 15/20、`xl` 20/26、タイムコード `tcL` 18・`tcM` 15・`tcXL` 22（等幅）。**和文は 12px 未満にしない**（例外はレールの 4 文字までのラベル 11px）。`xs`・`codeSm`（11px）は英数字だけに使い、素材名や和文が入りうる所（.mzc の行・場所の札・パス）は 12px にする。太さは sans が 400 と 600、mono が 400 と 500。
- **数字は等幅:** ttf.um に「0〜9 と `: ; . + -` の送り幅を、いちばん広い字にそろえる」モードを足す（タイムコード・数値の欄・ルーラー）。
- 省略は「…」。末尾を省くのが既定で、素材名は中央を省く。
- 字の描画はグレースケールのアンチエイリアスとガンマの補正。サブピクセルの描画はしない（OS で結果が変わるため）。倍率が変わったら、その倍率でラスタライズし直す。

### 17.3 余白と寸法

- 格子は 4px。余白は 4 / 8 / 12 / 16 / 24 / 32。
- 固定の寸法: 上の帯 40、レール 56、パネルの見出しとタブの帯 32、タイムラインの帯 36、ルーラー 26、状態の帯 24、トラックの見出し 176、メーター 40、項目の行 28（ラベルの幅 86）。
- 部品の高さ: 値の欄 24、ボタン 28（小 24、大 36）、アイコンボタン 28（小 24）、ダイアログの入力の欄 32。**押せる範囲は最低 24×24**（見た目が小さくても当たりは 24 に広げる）。

### 17.4 角・線・影

- 角: 3（クリップ・入力・札）、5（ボタン・メニュー）、8（カード・ダイアログ・通知）、丸（札の pill）。パネルには付けない。
- 線は 1px。選択とフォーカスは 2px。区切りは 1px の線か面の段差の**どちらか一方**。
- 影は浮かぶもの（メニュー・ツールチップ・コマンドパレット・ドラッグ中の物・通知・ダイアログ）だけで、`0 4px 12px rgba(0,0,0,.5)` の 1 種類（倍率ごとの 9 分割の画像で描く）。暗幕・ぼかし・大きな半透明は使わない（4K の全画面の半透明は CPU で重い）。ダイアログの後ろは何も重ねない（ダイアログの枠と影で分ける）。
- 斜線（45°、6px 周期）は「消える・削られる・素材がない・仮の位置」、点線（3-2）は「まだ確定していないもの（提案・参照・影）」の意味にだけ使う。素材がない（error・右上がり）と、仮の位置・削られるコマ（白・右下がり）は、色と向きの両方で分ける。

### 17.5 アイコン

- 格子 16×16（ツールバーとレールは 20×20）、線 1.5（100% で 1px か 2px に吸着）、端と角は丸、外周 1px は余白。塗りの版は「オン」の状態だけ（鍵・◆・再生）。
- 形がぶつからないように決めておくもの: エラーは丸に ×、警告は三角に !、リンクは鎖、参照は鎖に矢印、同期ロックは縦の 2 本線と錠前、ロックは錠前だけ。1 つのアイコンに 2 つの意味を持たせない。
- 第 1 版は約 72 個: 再生と移動 12、ツール 6、印 6、トラックの見出し 8、タイムライン 6、素材の種類 8、汎用 18、状態 5、書き手 3。
- **作り方:** アイコンを TrueType の glyf のフォント（私用領域 U+E000〜U+E0FF、「MozaicCut Icons」）にして同梱し、ttf.um のラスタライザとグリフのキャッシュで描く。どの倍率でもくっきり描け、SVG や PNG を読む処理を先に作らなくてよい。元の絵はモックアップの SVG の `<symbol>` で、変換は開発用のスクリプトで行う。

## 18. 動き

- **直接の操作（ドラッグ・スクラブ・トリム・再生ヘッド・ズーム）には動きを付けない。** 1 コマの中で追いつかせる。
- 時間（tokens.json の `motion.duration`）: ホバー 60ms（色だけ）、押下 0、ツールチップ 600ms 待つ（一度出たら隣はすぐ）、メニュー 120 ／ 100ms、パネルの開閉・トラックの高さ 160ms、ダイアログ 160ms（フェードと 4px）、リップルで後ろが詰まる 140ms、断られた操作が戻る 160ms、スナップの印 300ms、変わったものの強調 600ms、通知は 200ms で出て 4 秒（ボタン付きは 8 秒。操作の結果は通知にしない。14.1）。
- 曲線: 出るものは減速 `cubic-bezier(0.05,0.7,0.1,1)`、消えるものは加速 `cubic-bezier(0.3,0,0.8,0.15)`。
- 連続で操作しているとき（前の動きが終わる前に次の操作）は、前の動きをすぐ終わらせる（残像を出さない）。
- 「動きを減らす」: すべて 0ms（通知だけフェード、AI の明滅もやめる）。

## 19. アクセシビリティ

- **コントラスト:** 文字は 4.5:1 以上（主な文字は 7:1 以上）、アイコン・部品の境（`line.control`）・フォーカスの輪・波形・マーカーは 3:1 以上。tokens.json のすべての組み合わせの比を計算する **UM のテスト**を置き、下回ったら失敗にする（使ってよい組み合わせの表をテストに持つ）。**明るさの全段（−2〜+2）で回す。** 表に入れるもの: 文字 × `bg.0`〜`bg.4`、意味の色の文字 × その tint × `bg.1`・`bg.2`、`text.on*` × 塗り、クリップの文字・`clip.subText` × 面・選んだ面・札の地、波形 × 面、ラベル × `bg.1`・`bg.2`、再生ヘッド × 縁。
- **意味の色の距離:** 意味の色（と accent）のどの 2 つも CIEDE2000 で 20 以上（例外は playhead と error）。
- **フォーカス:** キーボードで動かしたときだけ、二重の輪（外は黒 1px、内は `accent` 2px、部品から 1px 離す）。アクティブなパネルは上の辺に `accent` の 2px の帯。Delete などのキーはこのパネルが受ける。
- **キーボードだけで全部を操作できる:** すべての操作がコマンドなので、キーを割り当てられる。パネルの間は F6 ／ Shift+F6、パネルの中は Tab と矢印、Enter で決定、Esc で取りやめ、メニューは Alt を単独で押して離す（標準と Premiere 互換は F10 も。Resolve 互換は Alt だけ。3.2）。タイムラインは ↑↓ で編集点、Alt+←→ でクリップを 1 コマ、Tab で同じ時刻のクリップを上下に。ダイアログと確認の欄はフォーカスを中に閉じ込め、閉じたら元の場所に戻す。
- **色だけに頼らない:** 種類は色＋アイコン＋縮小画像・波形、詰める ／ 詰めないは色＋文言、書き手は色＋アイコン（人・✦・`</>`）、エラーと警告は色＋アイコン（丸に × ／ 三角）＋文、オフラインは斜線＋文、ソロ ／ ミュートは塗り＋文字（S・M）、メーターは色＋数字の目盛り。
- **色覚の多様性:** 種類の色・ラベルの色・意味の色は、1 型・2 型・3 型のシミュレーションで、同じ場所に並ぶもの（種類の印とラベル、ローラーと再生ヘッド、詰める・詰めないの札、警告とエラー）が区別できることをテストで確かめる。色で区別できない組み合わせは、形（アイコン・斜線の向き・線の太さ）でも区別できるようにしてある。
- **スクリーンリーダー:** 自前で描く UI なので対応できない。そのことと、上の補い方（キーボード・色に頼らない・倍率）を説明書に書く。

## 20. UI の倍率

- 倍率 = OS の倍率（Windows の 125% ／ 150%、macOS の Retina、Linux の倍率）× 利用者の倍率（80〜200%、10% 刻み）。
- すべての寸法を「論理 px × 倍率」で持つ。線と面の境は、掛けたあとで整数の画素に吸着させる（1px の線は 125% でも 1px、150% で 2px にならないよう、線は `round(倍率)` px）。文字とアイコンは倍率ごとにラスタライズし直す（拡大した画像を使わない）。
- 125% と 150% もくっきり描く（Resolve の「100% と 200% しかない」への不満が参考）。
- 倍率 200% でも破綻しないように、2.1 の最小の大きさは論理 px で決め、窓が足りなければ 2.1 の順に畳む（1920×1080 の 200% は論理 960×540 で最小に届かないので、左の欄・右の列を畳み、上の帯と状態の帯を 2.1 の順に縮めた形になる。見本は edit.html?w=1024 の形と同じ）。
- 倍率が変わったとき（窓を別のディスプレイへ動かした）は、イベントで受けて作り直す（UM 側に要る。21.5）。

## 21. UM での実装の方針

### 21.1 部品（即時モード）

描画の種類を少なくする。

| 描画の種類 | 使う所 |
|---|---|
| 不透明の矩形 `rect` | 面・クリップ・帯 |
| 1px の枠 `frame` ／ 線 `line` | 区切り・枠・再生ヘッド |
| 角丸 `roundRect`（3 / 5 / 8 × 倍率の被覆率のマスクを先に作る） | ボタン・入力・カード・クリップ |
| アルファのマスクに色を掛けて描く `mask` | 文字・アイコン（どちらも ttf.um のグリフ） |
| 点線 `dash` ／ 斜線の塗り `hatch` | 提案・参照・影 ／ 消える・素材がない・仮の位置 |
| 9 分割の画像 `nine` | 浮かぶものの影 |
| 矩形の切り抜き `clip`（縦と横） | パネル・リスト・クリップの文字 |

半透明（`uiBlend`）は小さな面積（選択の面・斜線・札の地・ドラッグの影）だけに使う。

部品の一覧（どれも窓の中に描く）: パネル、タブ、ボタン（主・ふつう・弱い・危ない・アイコン）、トグル、セグメント、チェック、ラジオ、値の欄（ドラッグで値）、文字の欄（IME 対応）、スライダー、ドロップダウン、メニュー（右クリック・メニューバー）、ツールチップ、通知（トースト）、吹き出し、ダイアログ、リスト、グリッド、ツリー（ビン）、スクロールバー、分割の境目、キーの札、札（チップ）、進み具合（帯・回る印）、キーボードの絵。見本は [mockups/components.html](mockups/components.html)。

### 21.2 描画の作り

1. **3 つの層:** (a) プレビューのテクスチャ（新しいコマのときだけ送る。拡大縮小は SDL に任せ、`blitPreview` はやめる）、(b) UI（パネルごとに「汚れた」印を持ち、変わったパネルだけ描き直す）、(c) 重ね（再生ヘッド・ホバー・ドラッグの影・スナップの線・提案の重ね。毎コマ描く）。UM に層を分けた表示が足されるまでは、UI を Buffer に保持したまま変わったパネルだけ描き直し、全体を present する。
2. **イベントで動かす:** 何も変わっていなければ描かない。止まっているときは `pollWindowEvent(-1)` で眠り、裏の仕事の終わりで起こしてもらう（UM 側に要る）。それまでは、裏の仕事があるときだけ 8〜16ms で回す。いまの 0.4 秒ごとの `poll()` の描き直しはやめ、.mzc と probe が変わったときだけ読み直す。
3. **再生はワーカーで描く:** 先読みのリングバッファ（`RacyBuffer`）に数コマ先まで描き、メインスレッドは時計の時刻に合う一番新しいコマを出すだけ。間に合わないコマは飛ばし、数を数える。音を出せるようになったら音の時計を基準にする。
4. **トリム中・ドラッグ中・スクラブ中は 1/4 の画質**で描く。離したら正しく描く。
5. **wgpu の経路では、UI は CPU に固定**し、合成だけを GPU に置く（同じ Buffer で GPU と CPU を混ぜると毎コマ読み戻しが起きる）。受け渡すのはプレビューの 1 コマだけ。
6. **AI の比較は止まったコマ 1 枚ずつ**。再生中に 2 本描かない。

### 21.3 性能の目標

| 項目 | 目標 |
|---|---|
| UI の 1 コマの描画 | 4ms 以内（60fps の予算 16.6ms の残りを入力・送り・映像に使う） |
| 操作への反応 | 次のコマ（1 コマ以内） |
| 止まっているときの CPU | ほぼ 0（描かない） |
| 再生 | 1080p30、効果 5 個で 30fps（ロードマップの M1 の目標）。コマ落ちは数えて出す |
| 起動 | 窓が出るまで 0.5 秒、操作できるまで 1.5 秒 |

### 21.4 文字の作り

- 文字列ごとのキャッシュに、**1 文字ごとのグリフのアトラス**の層を足す。変わる数字（タイムコード）は 1 文字ずつ組み立てる。
- キャッシュの探し方をハッシュ表にする。末尾と中央の「…」の省略の関数を `src/ui/kit/` に足す（中央の省略はモックアップの `midEllipsis` を見本のテストにする）。等幅の数字のモードを `ttf.um` に足す。
- アイコンのフォントも同じアトラスで描く。

### 21.7 テスト

- **見た目の回帰:** いまの `--op --select --seek --shot` に `--state trim|empty|error|ai|export|start` を足し、mockups と同じ状態の BMP を書いて、前の版と比べる。
- **コントラスト:** tokens.json の組み合わせの比（19 章）を、明るさの全段（−2〜+2）で。
- **意味の色の距離:** CIEDE2000 で 20 以上（例外は playhead と error）。
- **色覚:** 種類・ラベル・意味の色のシミュレーション。
- **和文の大きさ:** 部品の見本の画面を描いて、和文が 12px 未満で描かれていないこと（例外はレールのラベル）。
- **キー:** 配列ごとに、同じキーが 2 つのコマンドに割り当たっていないこと（5.4 の表のすべての列）。Delete ／ Shift+Delete の意味がどの配列でも同じこと。IME がオンの状態を模したイベントでショートカットが効くこと。**IME の変換中の Enter で字幕が確定しないこと**（変換中の文字のイベントのあとの Enter は IME に渡る）。Alt を単独で押して離したときだけメニューに入り、Alt+ドラッグ・Alt+ホイール・Alt+C のあとでは入らないこと。
- **省略:** 中央の省略の関数が、どの幅でも「頭…尾」の形で幅に収まり、収まるなら省かないこと。
- **時刻:** 4.7 の往復。
