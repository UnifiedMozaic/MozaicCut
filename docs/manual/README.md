# MozaicCut 使い方の説明書

MozaicCut は、**テキストで編集する動画編集ソフト**です。プロジェクトは 1 行に 1 クリップのテキストファイル（`.mzc`）で、編集画面でも、コマンドでも、テキストエディタでも、AI のエージェントからでも、同じファイルを同じ操作で編集できます。

この説明書は、使う人のための手引きです。中の仕組み（モジュール、型、関数の形）は [../design/architecture.md](../design/architecture.md)、AI のエージェント向けの細かい決まりは [../ai.md](../ai.md) にあります。

## この説明書の読み方

- `mozcut` と書いてあるところは、MozaicCut のフォルダで実行する `node tools/mozcut.mjs` の略です。
- 例の出力は、この版で実際に実行して写したものです。パスは `C:\Users\you\...` のように読み替えてあります。
- **準備中** と書いてある機能は、まだ使えません。画面のデザイン（[../design/ui.md](../design/ui.md)）で決まっていても、この版に入っていないものは「準備中」と書いています。
- 版ごとに何が変わったかは [../../CHANGELOG.md](../../CHANGELOG.md) にあります。

## いまの版（0.18）でできること・できないこと

できること:

- **編集画面**: スタート画面（新しいプロジェクト・最近のプロジェクト・キーの割り当ての配列）、素材の欄、ソースとプログラムのモニター、タイムライン、インスペクタ、履歴、コマンドパレット（Ctrl+K）、ワークスペースの切り替え（カット編集・合成・色・音・出力）
- 素材を読み込む（ファイルのダイアログ、エクスプローラーからのドラッグ＆ドロップ）、タイムラインへ運ぶ、挿入・上書き
- クリップを並べる・重ねる・動かす・詰める・分ける・消す・範囲を切り取る、トランジション、速度の変更、映像と音のリンク、マーカー、イン点・アウト点（画面でもコマンドでも。画面ではどれも取り消せる）
- 動画・静止画・文字・単色・音に加え、図形（`shape`）、パーティクル（`particles`）、オーディオスペクトラム（`spectrum`）、3D のモデル（`model`、`.obj`）、プリコンポーズ（`comp`）の行
- キーフレームと式で値を動かす、親子付け、マスク、描画モード、3D レイヤー・カメラ・ライト
- 効果とトランジションのプラグイン（`.mzplug`。GPU が使えれば GPU で掛ける）、色の調整（ホイール・カーブ・スコープ）、音のミキサーとメーター、編集画面での音の再生（等速の順再生のとき）
- TrueType / OpenType のフォントで文字を描く（日本語・縦書き・縁取り・影・グラデーション・テキストアニメーター）
- 1 コマの画像（PNG / BMP）と、動画（H.264 + AAC の MP4）の書き出し（コマンドと「出力」の画面）
- 素材の音の文字起こし（手元の whisper.cpp）、AI のエージェントから MCP で使う、アプリの中の AI

準備中（この版にはまだありません）:

- キーを 1 つずつ割り当て直すこと（いまは 4 つの配列から選ぶだけ。[2.11](02-editing.md#211-キーの一覧編集画面)）
- キーの一覧に載っていても、まだ動かないコマンド: 再生ヘッドまで詰める・切る（Q / W / Alt+Q / Alt+W）、置き換え・上に置く・末尾に足す（Shift+F11 / F12 / Shift+F12）、編集点のまわりの繰り返し再生（/）、イン〜アウトの再生、逆向きのマッチフレーム（Shift+F）、手のひらツール（H）、トラックの高さを変えるキー、音量の線を常に出す（Ctrl+Shift+K） など（標準の配列のキー）
- 3D のモデルのモーションブラー・被写界深度・テクスチャ・材質（mtl）・glTF
- CFF2 の書体と、可変フォントの太さ以外の軸
- 画面の言葉の切り替え（いまは日本語だけ）
