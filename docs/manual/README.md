# MozaicCut 使い方の説明書

MozaicCut は、**テキストで編集する動画編集ソフト**です。プロジェクトは 1 行に 1 クリップのテキストファイル（`.mzc`）で、編集画面でも、コマンドでも、テキストエディタでも、AI のエージェントからでも、同じファイルを同じ操作で編集できます。

この説明書は、使う人のための手引きです。中の仕組み（モジュール、型、関数の形）は [../design/architecture.md](../design/architecture.md)、AI のエージェント向けの細かい決まりは [../ai.md](../ai.md) にあります。

## この説明書の読み方

- `mozcut` と書いてあるところは、MozaicCut のフォルダで実行する `node tools/mozcut.mjs` の略です。
- 例の出力は、この版で実際に実行して写したものです。パスは `C:\Users\you\...` のように読み替えてあります。
- **準備中** と書いてある機能は、まだ使えません。画面のデザイン（[../design/ui.md](../design/ui.md)）で決まっていても、この版に入っていないものは「準備中」と書いています。

## いまの版でできること・できないこと

できること:

- 動画・静止画・文字・単色・音のクリップを並べ、重ね、クロスフェードでつなぐ
- 分ける・詰める・動かす・消す・範囲を切り取る（コマンドと編集画面の両方。編集画面では取り消しも）
- クリップごとの効果（明るさ、コントラスト、彩度、白黒、セピア、反転、ぼかし、シャープ、ビネット、モザイク）と、画面全体への効果
- TrueType のフォントで文字を描く（日本語も。縁取り・影・背景の箱）
- 1 コマの画像（PNG / BMP）と、H.264 + AAC の MP4 の書き出し
- AI のエージェントから MCP で使う

準備中（この版にはまだありません）:

- 新しいデザインの編集画面（メディアプール、インスペクタ、ワークスペースの切り替え、コマンドパレット など）
- 色の調整の画面（カラーホイール、スコープ）、音の画面（ミキサー、メーター）、書き出しの画面
- 編集画面での音の再生、編集画面からのクリップの追加、ファイルを開くダイアログ、ドラッグ＆ドロップ
- 速度の変更、逆再生、キーフレームのアニメーション、図形・パーティクル・3D などのモーショングラフィックス
- 入れた wasm の効果プラグイン（`.mzplug`）を描画に使うこと
