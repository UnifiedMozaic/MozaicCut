# 6. AI と一緒に使う（MCP）

[目次](README.md) ／ 前: [5. 書き出す](05-export.md) ／ 次: [7. 困ったとき](07-troubleshooting.md)

MozaicCut は、AI のエージェント（Claude Code、Claude Desktop など [MCP](https://modelcontextprotocol.io/) に対応したもの）からも編集できます。AI が使うのは、人がコマンドで使うのと **同じエンジン・同じ操作** です。AI の編集も `.mzc` の該当する行だけを書き換えるので、人はいつでも中身を読み、編集画面やテキストエディタで直せます。

使い方は 2 通りあります。

| 使い方 | 向いているとき | 手引き |
| --- | --- | --- |
| MCP サーバー（`tools/mcp-server.mjs`）を登録する | Claude Desktop など、コマンドを打てないエージェント。触れるフォルダを決めて安全に使いたいとき | この章、詳しくは [../mcp.md](../mcp.md) |
| エージェントに `mozcut` のコマンドを打たせる | Claude Code のように端末を使えるエージェント | [../ai.md](../ai.md) |

## 6.1 MCP サーバーを登録する

必要なものは、コマンドが動く環境と同じです（Node.js、UnifiedMozaic、ffmpeg。[1.1](01-getting-started.md#11-必要なもの)）。以下のパスは例です。`C:/Users/you/MozaicCut` を MozaicCut の場所に、`C:/Users/you/Videos/projects` を **AI に触らせてよいフォルダ** に読み替えてください。

### Claude Code

```sh
claude mcp add mozaiccut -- node C:/Users/you/MozaicCut/tools/mcp-server.mjs --root C:/Users/you/Videos/projects
```

UnifiedMozaic が MozaicCut の隣にないときは、`-e UM_HOME=C:/Users/you/UnifiedMozaic` を `--` の前に足します。つながったかは `claude mcp list`、会話の中では `/mcp` で確かめられます。

### Claude Desktop

設定のファイル `claude_desktop_config.json`（Windows は `%APPDATA%\Claude\claude_desktop_config.json`。アプリの「設定 → 開発者 → 設定を編集」からも開けます）に足し、Claude Desktop を起動し直します。

```json
{
  "mcpServers": {
    "mozaiccut": {
      "command": "node",
      "args": [
        "C:/Users/you/MozaicCut/tools/mcp-server.mjs",
        "--root", "C:/Users/you/Videos/projects"
      ],
      "env": {
        "UM_HOME": "C:/Users/you/UnifiedMozaic",
        "FFMPEG": "C:/ffmpeg/bin/ffmpeg.exe",
        "FFPROBE": "C:/ffmpeg/bin/ffprobe.exe"
      }
    }
  }
}
```

- `--root` は必ず絶対パスで書きます。何度でも書けます（許すフォルダが増えます）。
- `node` や ffmpeg が PATH にないときは、`command` や `FFMPEG` / `FFPROBE` に絶対パスを書きます。

## 6.2 AI ができること

| ツール | すること | ファイルを書き換えるか |
| --- | --- | --- |
| `list_projects` | フォルダの中の `.mzc` を探す | しない |
| `schema` | キー・効果・操作の一覧を読む | しない |
| `check` | 診断と、全クリップの配置を読む | しない |
| `show` | タイムラインの図とクリップの一覧 | しない |
| `op` | 操作する。**既定は試すだけ**（差分を返す）で、`apply: true` のときだけ保存する | `apply: true` のときだけ |
| `preview` | 1 コマを画像にして、AI が見る | キャッシュに画像を書く |
| `render` / `render_status` | 書き出しを裏で始める・様子を見る・止める | 書き出し先に書く（あれば `overwrite: true` のときだけ） |

AI に頼むときは、ふつうの言葉で構いません。たとえば「`first.mzc` の main を 5 秒で分けて、後半をセピアにして。保存する前に差分を見せて」のように頼むと、エージェントは `check` で今の配置を読み、`op` を試して差分を見せ、確かめてから `apply: true` で保存する、という流れで動きます（この流れはサーバーの `instructions` にも書いてあります）。

## 6.3 安全のための決まり

- **許したフォルダ（`--root`）の外には触れません。** プロジェクト・素材・フォントが外を指していれば、ツールを動かす前に `outside-root` で断ります（OS のフォントのフォルダだけは、フォントに限って読めます）。
- **書き出すファイルは、プロジェクトのフォルダの中だけ** です。素材や `.mzc` そのものを書き出し先にすると、`overwrite` を付けても断ります（`output-is-source`）。
- **書き換える操作は、既定では試すだけ** です。失敗する操作・誤りを増やす操作は、何も書きません。
- 書き出し中のプロジェクトには、ほかのツールは触れません（`busy`）。

人が編集画面で同じプロジェクトを開いていても構いません。AI が保存すると、編集画面はすぐに読み直します。ただし、編集画面の Ctrl+Z は、AI の書き換えも消してしまうことがあります（[2.8](02-editing.md#28-取り消しとやり直し)）。

## 6.4 手で試す

サーバーは標準入出力で JSON を 1 行ずつやり取りします。登録の前に、端末で動くか確かめられます。

```sh
node tools/mcp-server.mjs --root C:/Users/you/Videos/myvideo
```

と起動して、次の行を 1 行ずつ入れると、答えが 1 行ずつ返ります。

```json
{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"me","version":"1"}}}
{"jsonrpc":"2.0","method":"notifications/initialized"}
{"jsonrpc":"2.0","id":2,"method":"tools/list"}
{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"op","arguments":{"project":"first.mzc","ops":"move title 1"}}}
```

`id` 3 の答えの文（`content` の 1 つ目）は、次のとおりです（[1.5](01-getting-started.md#15-プロジェクトを作る) の `first.mzc` で。試しただけで、保存していません）。

```text
試しただけで、保存していません（dry_run）。保存するには、同じ ops を apply=true で呼んでください。
- title を 0.5 秒から 1 秒に動かしました

差分:
@@ 6 行目（書き換え）
- text "はじめての動画" id=title at=0.5 dur=2 size=80 outline=000000
+ text "はじめての動画" id=title at=1 dur=2 size=80 outline=000000
```

許したフォルダの外のプロジェクトを渡すと、次のように断ります。

```text
エラー: プロジェクト C:\Users\you\Videos\other\demo.mzc は許したフォルダの外なので触れません。許したフォルダ:
  - C:\Users\you\Videos\myvideo
（ほかの場所を使うには、サーバーの起動に --root <フォルダ> を足してください）
```

標準入力を閉じると、サーバーは書き出し中のものを止めて後片付けをしてから終わります。
