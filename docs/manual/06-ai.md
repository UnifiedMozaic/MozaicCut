# 6. AI と一緒に使う（MCP）

[目次](README.md) ／ 前: [5. 書き出す](05-export.md) ／ 次: [7. 困ったとき](07-troubleshooting.md)

MozaicCut は、AI にも編集を頼めます。AI が使うのは、人がコマンドで使うのと **同じエンジン・同じ操作** です。AI の編集も `.mzc` の該当する行だけを書き換えるので、人はいつでも中身を読み、編集画面やテキストエディタで直せます。

使い方は 3 通りあります。

| 使い方 | 向いているとき | 手引き |
| --- | --- | --- |
| 編集画面の右の列の「AI」のタブで頼む | アプリの中だけで済ませたいとき。Claude の API キーか、手元の AI（Ollama、LM Studio など）があれば使えます | [6.5](#65-編集画面の-ai-のタブ) |
| MCP サーバー（`mozcut mcp`）を、Claude Code や Claude Desktop など [MCP](https://modelcontextprotocol.io/) に対応したエージェントに登録する | 触れるフォルダを決めて、エージェントにプロジェクトを編集させたいとき | [6.1](#61-mcp-サーバーを登録する)〜[6.4](#64-手で試す) |
| エージェントに `mozcut` のコマンドを打たせる | Claude Code のように端末を使えるエージェント | [../ai.md](../ai.md) |

## 6.1 MCP サーバーを登録する

MCP サーバーは、配布の形に入っている `mozcut.exe`（Mac は `MozaicCut.app/Contents/MacOS/mozcut`）に組み込まれています。`mozcut mcp --root <フォルダ>` で起動します。**Node.js や ffmpeg を別に入れる必要はありません。** 開発用のフォルダから使うときは、ビルドでできる `build/mozcut.exe` が同じものです。

以下のパスは例です。`C:/Users/you/MozaicCut/mozcut.exe` を `mozcut.exe` の場所に、`C:/Users/you/Videos/projects` を **AI に触らせてよいフォルダ** に読み替えてください。

### Claude Code

いちばん手早いのは、編集画面から登録の 1 行を写すやり方です。

1. 編集画面で、登録したいプロジェクトを開きます。
2. 左のレールの「設定」（またはメニューのファイル → 設定…）の先頭の「AI」で、相手を「Claude Code（外から）」にします。
3. 出てきた 1 行を［コピー］で写し、端末に貼り付けて実行します。`mozcut.exe` の場所と、開いているプロジェクトのフォルダが入っています。

手で書くなら、次のとおりです（`--` の後ろがサーバーの起動のしかたです）。

```sh
claude mcp add mozaiccut -- C:/Users/you/MozaicCut/mozcut.exe mcp --root C:/Users/you/Videos/projects
```

つながったかは `claude mcp list`、会話の中では `/mcp` で確かめられます。あとは Claude Code に「このプロジェクトの 3 秒から 5 秒を切って」のように頼みます。

### Claude Desktop

設定のファイル `claude_desktop_config.json`（Windows は `%APPDATA%\Claude\claude_desktop_config.json`、Mac は `~/Library/Application Support/Claude/claude_desktop_config.json`。アプリの「設定 → 開発者 → 設定を編集」からも開けます）に足し、Claude Desktop を起動し直します。

```json
{
  "mcpServers": {
    "mozaiccut": {
      "command": "C:/Users/you/MozaicCut/mozcut.exe",
      "args": ["mcp", "--root", "C:/Users/you/Videos/projects"]
    }
  }
}
```

- `--root` は絶対パスで書きます。何度でも書けます（許すフォルダが増えます）。`--root` を書かないと、サーバーを起動したフォルダだけを許します。Claude Desktop は起動するフォルダが決まらないので、必ず書いてください。
- `.mzc` を相対パスで渡すと、最初の `--root` のフォルダから探します。

> 開発用の Node.js 版のサーバー（`node tools/mcp-server.mjs --root <フォルダ>`）もあります。ツールは少ない（`list_projects`・`schema`・`check`・`show`・`op`・`preview`・`render`・`render_status`）代わりに、素材やフォントのパスまで許したフォルダの中か確かめます。使い方は [../mcp.md](../mcp.md) にあります。

## 6.2 AI ができること

| ツール | すること | ファイルを書き換えるか |
| --- | --- | --- |
| `list_projects` | 許したフォルダの中の `.mzc` を探す | しない |
| `create_project` | 新しい `.mzc` を作る（大きさ・fps・背景の色・BPM を決められる） | 作る（同じ名前があれば `overwrite: true` のときだけ） |
| `schema` | キー・効果・トランジション・操作・書き方の一覧を読む（`section` で絞れる） | しない |
| `check` | 診断と、全クリップの配置を読む | しない |
| `show` | タイムラインの図とクリップの一覧 | しない |
| `list_media` | プロジェクトのフォルダの中と素材の一覧（メディアプール）にある動画・画像・音を並べる（長さ・大きさ・fps・音があるか） | しない |
| `inspect_media` | 置く前に素材の中身を見る。動画は何コマかを並べた画像、画像は縮めた画像、音は長さなどの情報 | しない |
| `analyze_audio` | プロジェクトの音を調べ、BPM の見当・拍の時刻・盛り上がる所・静かな所を出す | しない |
| `transcribe` | クリップの話し声を書き起こし、字幕の区切りと、字幕を足す操作を出す | しない（字幕を置くには、出てきた操作を `op` に渡す） |
| `op` | 操作する。**既定は試すだけ**（変わる行を返す）で、`apply: true` のときだけ保存する | `apply: true` のときだけ |
| `preview` | 1 コマを画像にして、AI が見る（`out` を渡すとファイルにも書く） | `out` を渡したときだけ |
| `render` | 動画（MP4）に書き出す。終わるまで待ってから答える | 書き出し先に書く |

- `transcribe` は、手元の whisper.cpp で書き起こします（音を外のサービスに送りません）。whisper.cpp とモデルの置き方は [../analyze.md](../analyze.md) の「文字起こし」にあります。素材の長さに応じて時間がかかります。
- `%APPDATA%\MozaicCut\ai_guide.md`（Mac などは `~/.config/MozaicCut/ai_guide.md`）を置くと、その中身を AI への手引きに書き足します（「字幕は下に小さく」のような、自分の好みを書いておけます）。アプリの中の AI にも同じものを渡します。

AI に頼むときは、ふつうの言葉で構いません。たとえば「`first.mzc` の main を 5 秒で分けて、後半をセピアにして。保存する前に変わる所を見せて」のように頼むと、エージェントは `check` で今の配置を読み、`op` を試して変わる所を見せ、確かめてから `apply: true` で保存し、`preview` で見た目を確かめる、という流れで動きます（この流れはサーバーの `instructions` に書いてあります）。

## 6.3 安全のための決まり

- **プロジェクト（`.mzc`）と、書き出し・画像の保存先は、許したフォルダ（`--root`）の中だけ** です。外を指すパスや、`..` でさかのぼるパスは断ります。
- **書き換える操作は、既定では試すだけ** です。`op` は `apply: true` のときだけ保存します。どれか 1 つでも失敗する操作があれば、何も書きません。
- 確かめるのは、ツールに渡したパスだけです。`.mzc` の中に書いた素材やフォントのパスが外を指していても、そのまま読みます。触らせたくないファイルを指す `.mzc` は、許したフォルダに置かないでください。
- `render` は、書き出し先に同じ名前のファイルがあると上書きします。

人が編集画面で同じプロジェクトを開いていても構いません。AI が保存すると、編集画面はすぐに読み直し、その書き換えを取り消しの 1 つとして履歴に積みます。「履歴」のタブにも、何をしたかの 1 文の行が出ます（Ctrl+Z で AI の書き換えを戻せます。[2.8](02-editing.md#28-取り消しとやり直し)）。

## 6.4 手で試す

サーバーは標準入出力で JSON を 1 行ずつやり取りします。登録の前に、端末で動くか確かめられます。

```sh
C:/Users/you/MozaicCut/mozcut.exe mcp --root C:/Users/you/Videos/myvideo
```

と起動して、次の行を 1 行ずつ入れると、答えが 1 行ずつ返ります。

```json
{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"me","version":"1"}}}
{"jsonrpc":"2.0","method":"notifications/initialized"}
{"jsonrpc":"2.0","id":2,"method":"tools/list"}
{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"op","arguments":{"project":"first.mzc","ops":"move title 1"}}}
```

`id` 3 の答えの文（`content` の 1 つ目）は、次のとおりです（[1.5](01-getting-started.md#15-プロジェクトを作る) の `first.mzc` で。`"applied":false` なので、試しただけで保存していません。読みやすいように改行しています）。

```json
{"ok":true,"applied":false,"results":[{"op":"move","ok":true,"code":"",
 "desc":"title を 0.5 秒から 1 秒に動かしました", ...,
 "changes":[{"kind":"edit","line":6,
  "before":"text \"はじめての動画\" id=title at=0.5 dur=2 size=80 outline=000000",
  "after":"text \"はじめての動画\" id=title at=1 dur=2 size=80 outline=000000"}],
 "moved":[],"newDiagnostics":[]}],"diagnostics":[]}
```

許したフォルダの外のプロジェクトを渡すと、次のように断ります（`isError` が `true` になります）。

```text
許可されたフォルダ外のプロジェクトです: C:/Users/you/Videos/other/demo.mzc
```

標準入力を閉じると、サーバーは終わります。

## 6.5 編集画面の AI のタブ

編集画面の右の列の「AI」のタブからも、AI に編集を頼めます。AI は **提案だけ** を出し、あなたが適用するまでファイルは変わりません。AI が使うツールは MCP サーバーと同じもの（`check`・`show`・`schema`・`op`・`preview`・`list_media`・`inspect_media`・`analyze_audio`・`transcribe`）で、開いているプロジェクトだけを見ます。

### 相手を決める

左のレールの「設定」（またはメニューのファイル → 設定…）の先頭の「AI」で、相手を選びます。決めた内容は `%APPDATA%\MozaicCut\ai.json`（Mac などは `~/.config/MozaicCut/ai.json`）に書きます（API キーも平文で入るので、このファイルを人に渡さないでください）。

| 相手 | すること |
| --- | --- |
| Claude | Anthropic の Console で作った API キーを貼り付けて［保存］を押します（画面では最後の 4 文字だけを見せます）。環境変数 `ANTHROPIC_API_KEY` があれば、それを使うと出ます（ここで保存したキーのほうが先です）。モデルの既定は `claude-opus-5-5` です。使った分だけ料金がかかります |
| Ollama | Ollama を起動しておき、URL（既定 `http://localhost:11434`）を確かめて［一覧を取る］を押し、出てきたモデルを選びます。モデルがなければ、端末で `ollama pull <名前>` で入れます |
| OpenAI 互換 | LM Studio などのサーバーの base URL（例 `http://localhost:1234/v1`）とモデル（［一覧を取る］でも選べます）を入れます。キーが要る相手だけキーを入れます。料金を出したいときは、100 万トークンあたりの入力と出力のドルを入れます |
| Claude Code（外から） | アプリの中からは呼びません。出てくる 1 行（`claude mcp add …`）を［コピー］して端末で実行し、Claude Code で頼みます（[6.1](#61-mcp-サーバーを登録する)） |

［つながるか確かめる］を押すと、選んだ相手に小さな頼みを送り、つながったかどうかを出します。

### 使った量と料金の目安

- AI のタブでは、返事の下にその頼みで使った量（「入力 12.3k・出力 1.2k・約 $0.07」のような 1 行）が、タブの下に、この会話と今月の合計が出ます。Ollama は `$0（手元の AI）`、料金の表にないモデルは「料金が分かりません」と出ます。
- 設定の「AI」の「使った量（目安）」に、今月と先月の合計が出ます。「1 ドル」に円の値を入れると、円でも出します。［数をリセット］で記録を消します。記録は `ai.json` と同じフォルダの `ai-usage.json` です。
- どれも目安です。実際の請求は Anthropic の Console で確かめてください。

### 頼む・確かめる・適用する

1. 右の列の「AI」のタブの下の欄（Ctrl+J で移れます）に頼みを書き、［送る］（Ctrl+Enter）を押します。返事は届いたそばから出ます。途中でやめるときは［止める］を押します。
2. 提案ができると、「AI の提案」のカードが出ます。［確かめる］で、操作ごとの 1 文と `.mzc` の差分を見ます。いらない操作はチェックを外せます。
3. ［選んだ N 個を適用する］（Ctrl+Enter）で保存します。いくつ操作があっても、Ctrl+Z の 1 回で元に戻ります。［却下する］なら何も書きません。［修正を頼む］で、直してほしい点を書いて、その提案の続きとして AI に送れます。

提案を出した後にプロジェクトが変わって、提案が当てはまらなくなったときは、適用せずにそう出します。

相手の設定が足りないとき（キーがない など）は、タブに何をすればよいかの 1 文と［設定を開く］が出ます。つながらないときは、理由が赤で出ます。

## 6.6 準備中

- シーンの切れ目・無音・黒いコマを調べて、切る所を提案すること。解析の部品はできていますが、`mozcut` のコマンドと AI のツールにはまだつないでいません（[../analyze.md](../analyze.md)）。音の拍（`analyze_audio`）と書き起こし（`transcribe`）は使えます。
